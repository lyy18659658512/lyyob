# B站课程学习计划 Skill

## 概述

为 B 站视频课程一键生成完整的学习管理体系：解析视频章节 → 创建项目笔记 + 课程笔记 → 双向链接 → 按每日学习时长拆解任务清单。

**核心流程：**

1. 接收 B 站视频 URL
2. 获取视频信息（标题、UP主、章节与时长）
3. 询问用户每天学习时间（默认 30 分钟）
4. 创建课程笔记（`3 - KNOWLEDGE/1-Literature/2-Courses/`）
5. 创建项目笔记（`2 - ACTION/2-Learning/`）
6. 双向链接、任务拆解

---

## 模板定义格式，技能填充内容

**文件结构、YAML 字段、正文节标题——所有关乎"怎么写"的规则，均由模板定义。**

- 写入前读取对应模板，严格按模板的 YAML 字段、节标题和格式进行填充
- 模板中的 Templater 语法（`<% tp.date.now() %>`、`<% tp.file.title %>`）替换为实际值
- 技能只负责"提取什么"和"映射到哪个字段"，不规定"写成什么样"
- **若模板更新，技能自动适配，无需修改**

> ⚠️ **绝不自作主张**：YAML 字段中凡模板设为空值（`tags: []`、`links: []`、`aliases: []`、`instructor:` 等），技能不得自行填入内容，**原样保留**留给用户填写。

## 工作流程

### Step 1：获取视频信息

#### 1.1 提取 BV 号

从用户提供的 URL 中提取 BV 号。B 站 URL 格式通常为：

```
https://www.bilibili.com/video/BV1qE411H7Uv/
```

正则提取：`/video/(BV[a-zA-Z0-9]+)`。

#### 1.2 获取视频详情

**优先使用 WebFetch** 访问 B 站视频页面，提取：

- 视频标题
- UP主名称
- 视频结构（分P合集 或 单视频章节时间戳）

**如果 WebFetch 被拦截**（B站可能有反爬），使用 WebSearch 搜索 `bilibili {BV号} 分P 目录 时长`，从搜索结果中提取视频信息。

需要获取的关键信息：

| 信息 | 用途 |
|------|------|
| 视频标题 | 课程名、笔记标题 |
| UP主 | instructor 字段 |
| 章节/分P列表 | 任务拆解依据 |
| 每节时长 | 计算每日任务量 |

#### 1.3 计算总时长

将所有章节的时长（格式 `MM:SS` 或 `HH:MM:SS`）转换为分钟求和：

```
总分钟数 = Σ(分钟 + 秒/60)
然后将总分钟数向上取整到整数分钟。
```

### Step 2：确认学习节奏

向用户提问：

> 这个课程共 **N 节**，总时长约 **X 小时 Y 分钟**。你希望每天学习多长时间？
>
> 1. 30 分钟（默认，适合日常节奏）
> 2. 20 分钟（轻量）
> 3. 45 分钟（中等偏多）
> 4. 自定义：___ 分钟

等待用户回答后，记下 `dailyMinutes`。

> 如果用户已经在初始请求中说了每天多长时间，跳过此步直接使用。

---

### Step 3：任务拆解算法

输入：章节列表 `[{title, duration_minutes}]` + `dailyMinutes`

输出：分组后的每日任务列表 `[{day, tasks: [{title, duration}]}]`

**拆解原则（按优先级）：**

1. **不拆分单节**：一个章节的视频不拆分到两天
2. **尽量填满每天**：在不超过 `dailyMinutes` 的前提下组合多个短章节
3. **允许弹性**：实际日时长可在 `dailyMinutes` 的 ±40% 范围内浮动（如设定 30min，实际 18~42min 均可）
4. **短章节优先合并**：时长短的章节优先合并到同一天

**算法伪代码：**

```
days = []
current_day = {tasks: [], total: 0}

for each chapter:
    if current_day.total == 0:
        # 空天，直接加入
        current_day.tasks.add(chapter)
        current_day.total += chapter.duration
    elif current_day.total + chapter.duration <= dailyMinutes * 1.4:
        # 加入后不超上限，合并
        current_day.tasks.add(chapter)
        current_day.total += chapter.duration
    else:
        # 超上限，当前天结束，开启新天
        days.add(current_day)
        current_day = {tasks: [chapter], total: chapter.duration}

# 最后一天
if current_day.tasks:
    days.add(current_day)
```

### Step 4：创建课程笔记

#### 4.1 读取模板

读取 `[[9 - SYSTEM/Templates/课程笔记模板.md]]` 获取 YAML frontmatter 结构和正文节标题。

#### 4.2 组装 Frontmatter

| 模板字段 | 填充规则 |
|---------|---------|
| `title` | 视频标题 |
| `type` | 固定为 `course` |
| `platform` | 固定为 `B站` |
| `instructor` | 从视频信息提取 UP主名（无法获取则留空） |
| `url` | 用户提供的 B 站链接 |
| `progress` | 留空（模板默认） |
| `links` | `- "[[{项目笔记文件名}]]"` ← 链接到项目笔记 |
| `aliases` | 留空 |
| `created` | 当天日期 `YYYY-MM-DD` |
| `updated` | 当天日期 `YYYY-MM-DD` |
| `tags` | 留空 —— 用户自行填写 |

#### 4.3 组装正文

按模板结构填充：

- `# {课程名}` → 替换为视频标题
- `> **课程简介**：` → 填入「B站 UP主 **{UP主名}** 的系列课程，共 N 节，总时长约 X 小时。」
- `## 📚 课程大纲` → 列出完整章节目录（所有章节）
- `## 📖 学习笔记` → 保留空白占位
- `## 🎯 关键收获` → 保留空白占位
- `## 🔗 相关笔记` → `- [[{项目笔记文件名}]] ← 学习计划`

#### 4.4 写入文件

路径：`3 - KNOWLEDGE/1-Literature/2-Courses/{课程名}.md`

如果目标目录不存在，自动创建。

### Step 5：创建项目笔记

#### 5.1 读取模板

读取 `[[9 - SYSTEM/Templates/项目笔记模板.md]]` 获取 YAML frontmatter 结构和正文节标题。

#### 5.2 组装 Frontmatter

| 模板字段 | 填充规则 |
|---------|---------|
| `title` | `{课程名}学习计划` |
| `type` | 固定为 `project` |
| `created` | 当天日期 `YYYY-MM-DD` |
| `updated` | 当天日期 `YYYY-MM-DD` |
| `tags` | 留空 —— 用户自行填写 |
| `status` | `active` |
| `progress` | `"0/{总天数}"` |
| `startDate` | 当天日期 `YYYY-MM-DD` |
| `deadline` | 留空（模板默认） |
| `links` | `- "[[{课程笔记文件名}]]"` |

#### 5.3 组装正文

按模板结构填充：

**## 🎯 项目概述**

```markdown
跟随 B 站 UP 主「**{UP主名}**」的 **{课程名}** 系统学习。

- **平台**：B站
- **地址**：{视频URL}
- **UP主**：{UP主名}（如果有额外介绍可补充）
- **总章节**：N 节 | **总时长**：约 X 小时
- **计划**：每天约 {dailyMinutes} 分钟，共 {总天数} 天完成
```

**## ✅ 任务清单**

将 Step 3 的拆解结果按天排列为 checkbox 清单。

如果视频有明确的模块/章节划分（如「一、数与式」「二、方程与不等式」），在任务清单中用子标题分组。格式参考：

```markdown
### 📘 模块名（M节 · Day X–Y）

- [ ] **Day 1**　#1 章节名 (时长) + #2 章节名 (时长)　`≈XXmin`
- [ ] **Day 2**　#3 章节名 (时长)　`≈XXmin` 🟢轻量日
```

标注规则：
- 当天总时长 < dailyMinutes × 0.6 → 标注 `🟢轻量日`
- 当天总时长 > dailyMinutes × 1.2 → 标注 `🔴重点`
- 单个章节时长 > dailyMinutes × 1.0 → 标注 `🔴重点`

**## 📊 进度总览**（可选但推荐）

在任务清单后添加一个模块进度表：

```markdown
| 模块 | 节数 | 天数 | 进度 |
|------|:---:|:---:|------|
| 📘 模块一 | M | Day X–Y | ⬜ |
| **合计** | **N** | **D 天** | **0/D** |
```

**## ⚠️ 问题与阻塞** → 保留空白

**## 🔗 相关资源** → `- [[{课程笔记文件名}]] ← 课程笔记` + B站链接

#### 5.4 写入文件

路径：`2 - ACTION/2-Learning/{课程名}学习计划.md`

## 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| **WebFetch 被拦截** | 使用 WebSearch 搜索 `bilibili {BV号} 分P 目录 时长` |
| **视频无章节划分** | 按视频总时长估算：`天数 = ceil(总时长 / dailyMinutes)`，每天标注「观看视频 X~Y 分钟」 |
| **单章节超 dailyMinutes** | 该章节独占一天，标注 `🔴重点` |
| **多分P合集** | 每个分P作为一个章节处理 |
| **单视频+时间戳** | 每个章节时间戳作为一个章节处理 |
| **无法获取章节信息** | 告知用户视频信息获取失败，仅创建框架笔记（含链接和基本信息），任务清单标注「请手动补充章节信息」 |
| **课程名含非法字符** | `: / * ? " < > \|` → 替换为全角 `：／＊？＂＜＞｜` 或空格 |
| **目标目录不存在** | 自动创建 |
| **同名文件已存在** | 询问用户是否覆盖、合并或改名 |
