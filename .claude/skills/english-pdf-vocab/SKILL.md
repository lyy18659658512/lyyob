# 英文 PDF 辅助阅读（术语 + 对照翻译）

## 概述

从英文 PDF 文件中提取文本后，产出两部分内容：

1. **关键字中英对照表** — 提取关键学科/技术术语，让用户快速查词
2. **原文中英对照翻译** — 逐段给出原文和中文翻译，**数学公式、符号、算式保留原样不翻译**

用户既可以速查术语，也可以对照原文学习英文表达。

## 触发方式

| 触发短语 | 场景 |
|---------|------|
| "翻译关键词"、"中英对照"、"提取术语" | 直接请求术语表 |
| "帮我读这个PDF"、"英文PDF辅助" | 请求 PDF 阅读辅助 |
| "帮我翻译一下这个习题"、"翻译一下左侧的" | 当前笔记是英文 PDF 时的自然表达 |
| "keyword help"、"vocabulary"、"术语对照" | 英文表达 |

当 `<current_note>` 指向一个 PDF 文件且用户询问其内容时，自动判断是否需要辅助。

## 工作流程

### Step 1：定位 PDF

按以下优先级确定目标 PDF：
1. `<current_note>` 中指向的 PDF 文件
2. 用户消息中 `@` 引用的 PDF 文件
3. 用户明确指定的文件路径

### Step 2：提取文本

使用 `pdftotext` 提取 PDF 文本：

```bash
pdftotext -layout "path/to/file.pdf" -
```

如果 pdftotext 不可用，回退到 Python（`pdfplumber` 或 `PyPDF2`）。

### Step 3：识别关键术语并翻译

从提取的文本中识别关键术语：

| 优先级 | 类型 | 示例 |
|--------|------|------|
| **高** | 学科核心术语 | linear combination, zero vector, matrix, eigenvalue |
| **高** | 题目中的关键词 | invertible, independent, dependent, multiply |
| **中** | 学术常用动词/名词 | find, solve, determine, equation, solution |
| **低** | 通用学术表达 | true or false, lie in, following |

**筛选标准**：
- 对该学科/主题的理解起关键作用的词
- 反复出现的术语
- 用户可能不熟悉的学术用词
- 不收录：基础词（a, the, is, of）、简单词（good, bad, big）

**翻译标准**：
- 优先采用该学科领域的标准译法
- 一词多义时结合上下文选择最贴切译法

### Step 4：逐段原文中英对照翻译

将提取的文本按自然段落分割，逐段给出原文和中文翻译。

**核心规则**：
- 数学表达式、公式、矩阵、向量等**用 `[式子]` 或 `[矩阵]` 占位代替**，不输出原始 LaTeX 或符号，保持排版简洁
- 如果一句英文中包含数学符号，翻译时同样用占位符代替，如 "Multiply `[矩阵]` `[向量]`" → "计算 `[矩阵]` 乘以 `[向量]`"
- PDF 中原本的空白/填空题（如 `______`）保留原样
- 选择题的括号选项（如 `(independent)(dependent)`）翻译时写成中文选项格式

### Step 5：输出

输出结构：先来源说明，再关键字对照表，最后逐段对照翻译。

```
> 📎 来源：{课程名/书名} · {章节}

## 关键字中英对照

| 英文 | 中文 |
|------|------|
| **term 1** | 翻译 1 |
| ... | ... |

## 原文中英对照翻译

**原文**：{英文原文，数学式子用 [式子]/[矩阵]/[向量] 占位}
**翻译**：{中文翻译，数学式子同样用占位符代替}

**原文**：...
**翻译**：...
```

## 输出示例

用户打开 `MIT18_06SCF11_Ses1.1prob.pdf` 并说 "帮我翻译一下左侧的习题"：

---

> 📎 来源：MIT 18.06SC Linear Algebra · Session 1.1 习题

## 关键字中英对照

| 英文 | 中文 |
|------|------|
| **geometry** | 几何 |
| **linear equations** | 线性方程（组） |
| **combination** | 组合 |
| **zero vector** | 零向量 |
| **independent / dependent** | 独立的 / 相关的 |
| **matrix** | 矩阵 |
| **column** | 列 |
| **invertible** | 可逆的 |
| **multiply** | 相乘 |
| **true or false** | 判断正误 |

## 原文中英对照翻译

**原文**：Find a combination [式子] that gives the zero vector: [三个向量 w1, w2, w3]

**翻译**：求组合 [式子] 使结果为零向量：[三个向量 w1, w2, w3]

**原文**：Those vectors are (independent)(dependent). The three vectors lie in a ______. The matrix W with those columns is not invertible.

**翻译**：这些向量是（独立的 / 相关的）。这三个向量位于一个 ______ 中。以这些向量为列构成的矩阵 W 不可逆。

**原文**：Multiply: [3×3 矩阵] × [3×1 向量]

**翻译**：计算矩阵乘法：[3×3 矩阵] × [3×1 向量]

**原文**：True or false: A 3 by 2 matrix A times a 2 by 3 matrix B equals a 3 by 3 matrix AB. If this is false, write a similar sentence which is correct.

**翻译**：判断正误：一个 3×2 矩阵 A 乘以一个 2×3 矩阵 B，结果等于一个 3×3 矩阵 AB。如果这句话是错的，请写出一句正确的类似表述。

## 边界情况

| 情况 | 处理 |
|------|------|
| PDF 无法提取文本（扫描件/图片型） | 告知用户此 PDF 为图片格式，无法提取文本，建议使用 OCR 工具 |
| PDF 内容极少（如只有几行公式） | 提取能识别的少量术语，注明 PDF 内容以公式为主 |
| 多个 PDF 同时涉及 | 询问用户优先处理哪一个 |
| 非英文 PDF | 说明本技能目前仅支持英文 |
| pdftotext 和 Python 均不可用 | 报告无法提取文本，建议用户安装 pdftotext 或 pdfplumber |
| 用户只需要术语表、不需要全翻译 | 可省略逐段对照翻译部分，只输出术语表 |
