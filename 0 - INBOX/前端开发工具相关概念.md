# 前端开发工具相关概念

- CLI 工具 是具体的命令行程序或脚本，专注于完成特定任务。CLI（Command-Line Interface）工具是指通过命令行与用户交互的软件工具。  
    
- 常见CLI工具：  
    
    - Git：用于版本控制的工具，允许开发者管理代码的历史记录和协作开发。  
        
    
    - Node.js：一个基于 JavaScript 的运行时环境，常用于构建服务器端应用程序，同时也提供了丰富的 CLI 工具生态系统。  
        
    
    - npm/yarn：JavaScript 包管理器，用于安装和管理项目依赖。  
        
    
    - Docker：用于创建、部署和运行容器化应用程序的工具。  
        
    
    - curl/wget：用于从网络下载文件或与 Web 服务进行交互的工具。  
        
    
    - ssh：用于安全地连接到远程服务器的工具。  
        
    
    - grep/sed/awk：用于文本处理和搜索的工具。  
        
- 终端 是一个交互界面，提供了一个环境让用户可以运行 CLI 工具并查看输出。一个终端可以运行多个不同的 CLI 工具。例如，在同一个终端中，你可以先后运行 git status、npm start 和 python script.py  
    
- 简单来说，终端是舞台，CLI 工具是演员。  
    
- VS Code 集成终端 和 独立终端 并不矛盾，它们各有优劣，适用于不同的场景。运行和调试命令 可以通过 VS Code 的集成终端执行，但在某些情况下（如系统管理、多任务处理或学习命令行工具）独立终端可能更合适。

- HTML 并不是一种编程语言，而是一种标记语言。它通过定义网页的结构和内容，帮助浏览器理解如何展示页面。HTML 的“运行”实际上是浏览器解析 HTML 文件并将其渲染为可视化的网页的过程。如果需要实现动态功能，则需要结合 JavaScript 等编程语言来完成。  
    
- JavaScript 是通过操作 DOM（文档对象模型，Document Object Model） 来让交互结果显示在浏览器上的。DOM 是 HTML 文档的编程接口，它将网页中的所有元素表示为一个树状结构，JavaScript 可以通过这个树状结构来访问、修改或删除页面上的内容。它的主要步骤包括：  
    
    - 选择元素：通过 DOM API 找到需要操作的元素。  
        
    
    - 修改内容或样式：通过修改元素的属性（如 innerHTML、style 等）来改变页面内容。  
        
    
    - 监听事件：通过事件监听器捕获用户的操作。  
        
    
    - 更新页面：根据用户的操作动态更新 DOM，浏览器会自动重新渲染页面。  
        
    
    - 简单来说，JavaScript 就像一个“桥梁”，它连接了用户的操作和页面的变化，使得网页可以变得动态和交互性强。
