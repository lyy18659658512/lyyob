> [!tip]+ 爬虫基本策略
> 优先分析目标网站结构，尽量找数据接口直接获取 JSON 数据，避免解析 HTML。
>
> - **检测 JS 加载**：在浏览器中禁用 JavaScript，观察页面内容是否正常展示
>   - Chrome：设置 → 隐私和安全 → 网站设置 → JavaScript → 关闭
> - **查看网页结构**：用 python 请求下载一个网页查看

> [!warning]- User-Agent 检测
> 设置真实 UA，使用 fake_useragent 随机化

> [!warning]- IP 限制 / 封禁
> 使用代理 IP，控制访问频率，构建代理池

> [!warning]- 验证码
> 识别简单验证码（OCR）、接入打码平台、模拟操作

> [!warning]- 请求频率过高
> 设置随机延时，限制并发，降低爬取速度

> [!warning]- 动态内容（JS/AJAX）
> 分析 API 接口，或使用 Selenium/Playwright

> [!warning]- Cookie / Session
> 使用 requests.Session() 保持会话

> [!warning]- 请求头检测
> 补全 Referer、Accept 等请求头

> [!danger]- 行为检测（高级）
> 模拟人类操作，如滚动、点击、停留

> [!danger]- TLS/指纹检测（高级）
> 使用真实浏览器工具（如 Playwright）
