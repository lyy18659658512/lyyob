> [!terminal]- Git 常用命令
> ```bash
> git init                                    # 初始化本地仓库
> git add .                                   # 暂存所有更改
> git commit -m "提交信息"                    # 提交更改
> git remote -v                               # 查看远程仓库
> git remote set-url origin <地址>            # 更改远程仓库地址
> git remote add origin <地址>                # 关联远程仓库
> # (https://github.com/your-username/your-username.github.git)（不带.io是普通项目仓库） 
> # (https://github.com/your-username/your-username.github.io.git)（带.io是特殊的仓库，用于静态网站托管服务：GitHub Pages）
> git push -u origin main                     # 推送代码
> git clone <地址>                            # 克隆仓库到本地
> ```

> [!terminal]- 虚拟环境
> ```bash
> python -m venv myvenv                       # 创建虚拟环境
> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser  # 允许执行脚本
> .\myvenv\Scripts\Activate.ps1               # 激活虚拟环境
> deactivate                                  # 退出虚拟环境
> ```

> [!terminal]- pip & 打包
> ```bash
> pip list                                    # 查看已安装的包
> pip show <包名>                             # 查看包详细信息
> pip install pyinstaller                     # 安装打包库
> pyinstaller --noconfirm --onefile --windowed --add-data "config.json;." main.py
> ```
>
> 打包说明：
> - `--onefile`：打包为单个 exe
> - `--windowed`：不显示黑窗口
> - `--add-data "config.json;."`：将配置文件一起打包
>
> ✅ 打包后位于：`dist/main.exe`
> 可以将此 main.exe和（如果需要）config.json一起提供给用户使用，或直接双击运行！
