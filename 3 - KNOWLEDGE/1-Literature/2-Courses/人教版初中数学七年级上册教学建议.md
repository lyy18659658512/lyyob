# 人教版初中数学七年级上册教学建议

> 在知识的结构化建构和综合应用中发展学生的数学核心素养

## 📚 目录
#### 一、课标《2022年版》的教学建议
#### 二、教科书（七年级上册）内容的组织方式与逻辑结构
#### 三、整体教学建议
#### 四、分章教学建议

## 📖 整体教学建议
1. 加强数与式的整体性
2. 加强数与式与方程的关联性
3. 重视方程建模活动，发展模型观念
4. 注重从实验几何到推理几何的过渡

## 📖 分章教学建议
#### 第一章 有理数
1. 加强与小学学习的衔接，适当复习，总结数的扩充的基本框架，创设情境，提出相反意义量的表示问题，引入负数，发展抽象能力
2. 用数系扩充思想作为教学主线，提出研究问题
3. 重视表示非0有理数符号的理解，用正负号表示方向，用数字表示量值
4. 重视数轴概念的教学，借助数轴理解相反数与绝对值的概念，抽象有理数的大小比较法则，体会数形结合思想，发展抽象能力，建立几何直观
5. 重视基于类比、归纳的学习活动设计
#### 第二章 有理数运算
1. 以数系扩充为主线进行单元及课时教学设计
2. 注意中小学衔接，从已有的运算经验出发，归纳有理数的运算法则，加法运算——基于运动情境
3. 重视运算律教学，帮助学生理解运算律与算法之间的关系
4. 重视运算能力培养
5. 重视学以致用
#### 第三章 代数式
1. 加强数与式的类比教学，初步理解数式通性
2. 重视列代数式表示数量关系的教学
3. 通过代数式的值的教学帮助学生理解代数式与数的“抽象”与“具体”关系
4. 通过用代数式表示反比例关系，体会代数式是研究一类数量关系模型的符号工具
#### 第四章 整式的加减
1. 注重与代数式一章的有机联系
2. 加强数与式的类比，基于运算律理解整式的加减
3. 打好运算基础，发展运算能力
4. 学以致用
#### 第五章 一元一次方程
1. 重视方程建模活动，体会方程是刻画现实中等量关系的重要数学模型，列方程解决问题的一般步骤：审——设——列——解——检——答
2. 加强基于等式基本事实和运算性质的推理
3. 加强与代数式的联系
#### 第六章 几何图形初步
1. 重视几何概念和命题的抽象过程，为几何推理奠定直观和逻辑基础
2. 注意与小学学习衔接
3. 加强直观性
4. 适当把握教学要求
