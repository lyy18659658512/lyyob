# 高中数学基础与解法全集（涵盖所有）

> **课程简介**：B站 UP主 **一数**（全国高中数学联赛一等奖、中国数学奥林匹克夏令营一等奖保送生）的系列课程，共 220+ 节，总时长约 107 小时。从零开始、通俗易懂，涵盖高中数学全部核心内容。

1. 一数指南
2. 初高衔接】1 等式变形方法回顾
	1. ![[Pasted image 20260723210501.png]]
	2. 因式分解时，对于两个变量的多项式，把其中一个看成**主元**
	3. 因式分解的技巧：可以先猜根，得到其中一个因式，再推导其他因式，可用**长除法**
3. 初高衔接】2 不等式解法梳理
	1. 分式不等式转化成一元二次不等式后，注意**排除分母等于零的点**
	2. 高次不等式解法→**穿根法（奇穿偶不穿）画图**，符号决定上穿还是下穿，画完图象可用特殊值检验函数值正负与图象是否相符合![[Pasted image 20260723220656.png]]
