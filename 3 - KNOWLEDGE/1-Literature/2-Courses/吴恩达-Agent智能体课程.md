# 吴恩达-Agent智能体课程

> **课程简介**：吴恩达主讲的最新 AI Agent 智能体课程，系统讲解 Agent 的四种核心设计模式——Reflection（反思）、Tool Use（工具使用）、Planning（规划）、Multi-agent（多智能体协作），附带课件代码，从入门到进阶。

## 📚 课程大纲

1. **课程介绍** — Agent 概述，为什么 Agent 是 AI 的下一个前沿
2. **Reflection（反思）模式** — Agent 自我纠错与迭代优化
3. **Tool Use（工具使用）模式** — Agent 调用外部工具扩展能力
4. **Planning（规划）模式** — Agent 自主规划任务路径
5. **Multi-agent（多智能体协作）** — 多个 Agent 协同完成任务
6. **总结与实践** — 完整项目实战

## 📖 学习笔记

### 第 1 课：课程介绍 + Agent 概述

- #### **概述**
	- 构建agent的关键是能否推动有纪律的开发流程，尤其是评估和错误分析流程
	- agent：LLM执行多个步骤完成任务
	- 智能体可按自主性高低进行划分，自主性高的智能体通常更难控制，更加不可预测
- #### **智能体工作流的优势**
	1. 相比LLM更适用具体场景
	2. 能够并行处理
    3. 模块化设计
-  #### **构建agent最重要的技能**
	1. 分析复杂流程找出各个独立步骤
		- 将任务分解成多个独立步骤，分析每一步是否可以由大模型实现，是否可以调用相应API工具或函数。
		- 如果都不能，分析人类如何完成，可否进一步拆解。
	2. 通常初步分解后，需要不断迭代优化
		- 构建评估方法
			- 对于难以预知可能出现什么问题的智能体工作流，可以先从输出入手，找出输出不满意的地方，基于这些寻找评估和改进系统的方法
				1. 编写代码计算错误频率，形成客观的量化指标来衡量评估客观标准
				2. 让LLM自己来评估主观标准
				3. 端到端的评估（端测）
				4. 组件级评估：评估智能体流程中某一步的输出质量（单测）
		- 推动规范的评估流程
- #### **构建智能体工作流的设计模式**
	1. **反思/Reflection**：让大模型检查自己的输出，或反馈外部信息让它修改；也可用另一大模型扮演批评者对输出进行审查
	2. **工具使用/Tool Use**：调用外部工具扩展能力
	3. **规划/Planning**：制定多步执行计划
	4. **多智能体协作/Multi-agent collaboration**：多个智能体分工协作
