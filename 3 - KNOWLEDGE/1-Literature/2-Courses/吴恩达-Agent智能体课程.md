# 吴恩达-Agent智能体课程

> **课程简介**：吴恩达主讲的最新 AI Agent 智能体课程，系统讲解 Agent 的四种核心设计模式——Reflection（反思）、Tool Use（工具使用）、Planning（规划）、Multi-agent（多智能体协作），附带课件代码，从入门到进阶。

## 📚 课程大纲

1. **课程介绍** — Agent 概述，为什么 Agent 是 AI 的下一个前沿
2. **Reflection（反思）模式** — Agent 自我纠错与迭代优化
3. **Tool Use（工具使用）模式** — Agent 调用外部工具扩展能力
4. **Planning（规划）模式** — Agent 自主规划任务路径
5. **Multi-agent（多智能体协作）** — 多个 Agent 协同完成任务
6. **总结与实践** — 完整项目实战
