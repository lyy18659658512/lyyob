## 📖 学习笔记
### 一、数与式
1. 数与式概念：
   - 数：
      - **有理数**
         - 整数
         - 分数
      - **无理数**
   - 式：
      - **有理式**
         - **整式**
            - 单项式
            - 多项式
         - **分式**
      - **无理式**
2. 绝对值的意义和解题方法：
   - 含绝对值的不等式或方程的解法：
      - **几何法**
      - **分类讨论法**（去掉绝对值符号，再求并集）
   - 关于解含绝对值符号的不等式的理解：不加绝对值的解集是A，加绝对值的解集是B，一句话概括：A 是”坐标”的解集，B 是”距离”的解集，而 B 的形状，就是 A 的右半边在数轴上照的一面镜子。因此B总是关于y轴对称
3. 乘法公式大全以及使用方法：
   - **杨辉三角**是二项式系数的图象
   - **对称多项式基本定理**：任何一个对称多项式，都可以用初等对称多项式进行唯一表示，**韦达定理**的两根之和与两根之积是典型的初等对称多项式
4. 配方的进阶技巧：
   - 注意配方顺序，二次项系数如果不是 a² 的形式，例如12，则提出公因式3，使得系数变成4再进行配方
5. 因式分解：
   - 三项相加化成两项相乘：`ab+ad+bc = (a+c)(b+d) - cd`
   - 高次方程的根的问题，通过因式分解，分解成二次方程与不为0的因式的乘积，从而转化为二次方程根的问题
### 二、方程与不等式
1. 求解分式方程最后需要**验根**
2. 化简求取值范围，注意化简过程中分子分母消去含参式子时，要加**含参式 ≠ 0**的条件
3. 方程有两个实根 → **Δ ≥ 0**，有两个不等的实根 → **Δ ＞ 0**
### 三、函数
1. 二次函数系数 **a、b、c** 的作用：
   - **a** → 确定**开口方向**，a 的大小影响开口的大小
   - **b** → **对称轴**的位置，x = -b/2a
   - **c** → 与 **y 轴的交点**
2. 比较二次函数的函数值 y 的大小 = 比较自变量 x 与**对称轴的距离**
3. 含参一元二次方程题型：
   - **最值**：分类讨论 a＞0 / a＜0，分类讨论对称轴与已知自变量区间的关系
   - **根的分布**：转换成 **Δ**、函数值、对称轴
   - **不等式**：不等式解集与方程的根相互转化，注意
   - 分类讨论 a＞0 / a＜0，分类讨论含参数根与已知根的大小关系
### 四、几何
1. 全等：
   - **SSS**
   - **SAS**
   - **AAS**
   - **ASA**
   - **HL**
2. 相似：
   - 判定：
      - 全等
      - 两角对应相等
      - 两边对应成比例，夹角相等
      - 三边对应成比例
      - **RT▲**：任意两边成比例
   - 性质：
      - 周长之比 = **k**
      - 面积之比 = **k²**
      - 不同直线被三条平行线所截成的线段之间比例相等
3. 角平分线问题：
   - 构造角平分线上的点到两边的垂线
   - **角平分线定理**：▲ABC 中，若 AD 是角平分线，则 AB/AC = BD/DC
4. 直角中的”特殊型”：![[202607071741.PNG]]
5. 利用相似计算长度与比例关系
	- 模型 
		1. 8字型
		2. 反8字型
		3. A字型
		4. 射影定理
	- 已知一条直线上两条边比例，求另外两条边比例的解题思路
		1. 利用平行，找8字型相似，转化成两个相似三角形对应边的比例
		2. 通过边的等量代换转化成同一个三角形中的两条边的比例，再找这个三角形的相似三角形
	- 翻折问题
		1. 利用直角特殊型的相似
6. 圆的知识梳理
	1. 弧长相等，圆周角相等
		1. 转角思路：直角三角形斜边上的中线构成两个等腰三角形
	2. 垂径定理，平分弦长，平分弧长
		1. 结合平行线分线段成比例定理，证明线段相等或成比例
		2. 线段相等转化为角相等
	3. 内心（角平分线交点）、外心（垂直平分线交点）
	4. 圆与点，圆与直线的位置关系
	5. 弦切角定理，需证明，不能直接用
	6. 扇形弧长公式l=nΠR/180，面积公式S=nΠR²/360=1/2 Rl
	7. 四点共圆![[Pasted image 20260710124210.png]]
	8. 圆幂定理（不能直接用，需证明）![[Pasted image 20260710124345.png]]

8. 圆与内接四边形题型解题思路![[Pasted image 20260710182925.png]]
9. 圆中线段的积与商
		1. 根据所求的积和商，做辅助线，找相似三角形
		2. 证明相似的方法，除了两个角相等还可以，一个夹角+对应边成比例
10. 圆中线段的计算方法
	1. 相似/全等

### 五、函数压轴
1. 求函数上动点组成特殊三角形
	- 注意分特殊三角形要**分类讨论不同顶点**
2. 求函数上动点是否能组成平行四边形
	- 首**先分类讨论已知的两个顶点连线是边还是对角线，再分类讨论不同连线顺序**
3. 求函数上动点是否能组成特殊平行四边形
	- 先用平移求成平行四边形的点，再用勾股定理或对角线相等验证点是否成矩形，或用边长是否相等验证是否是菱形
