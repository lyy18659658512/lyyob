## 📖 学习笔记
#### 教科书编写背景
1. 2012年，十八大，立德树人
2. 2017年，普通高中各科课程标准（2017版）
3. 2018年，德智体美劳，六个下功夫
4. 2019年，**启发式、互动式、探究式**教学
5. 2020年，探索增值评价
6. 打造**培根铸魂、启智增慧**的精品教材——习近平2020.11.29
7. 2022年，二十大，实施科教兴国战略，强化现代化建设人才支撑
#### 教科书编写指导思想
1. 整体层面：以习近平新时代特色社会主义思想为指导，落实党的二十大精神、立德树人
2. 数学学科：发展数学核心素养为宗旨、获得四基、培养四能，人人都能获得良好的数学教育，不同的人在数学上得到不同的发展
#### 教科书编写目标
1. 融入中国特色社会主义思想、优秀传统文化，落实立德树人根本任务，体现数学学科育人价值和功能
2. 以课标为依据，反映数学本质，重视思维过程，发展核心素养
3. 遵循教育教学规律和学生身心发展规律，促进学生学会学习、学会思考，促进教师转变教学观念，改进教学方式，提高教学质量
4. 创新呈现方式，培养学生理性思维和勇于探索创新的科学精神，打造具备中国特色的初中数学教材
5. 通过教材修订和专业化的教材制作，为实现数学课程目标、发展数学核心素养提供优质教学资源

#### 教科书编写过程
1. 组建结构合理的编写队伍
2. 开展扎实的教材编写基础研究
3. 按照规范的流程开展编写工作
#### 教科书结构体系
1. 数与代数、图形与几何、统计与概率、综合与实践四个学习领域![[Pasted image 20260822161733.png]]
2. 遵循逻辑性、连续性、整体性、关联性原则
3. 数与代数
	1. 数、式、方程、不等式、函数——反映了认识事物的角度和深度的变化，即从数（量），到数量关系，到等量关系、不等关系，到变量关系
	2. 整体上，一次方程、一次不等式、一次函数到二次方程、二次不等式、二次函数螺旋上升
	3. 具体地
		1. **负数移入到初中学习**
		2. 整式加减之前安排“代数式”一章
		3. 整式乘法、因式分解容易混淆，拆分成单独两章
		4. 方程、不等式重视**消元、降次、系数化为1**等基本思想
		5. 将函数与一次函数分章安排，一次函数内容结构更清晰，便于后续的二次函数、反比例函数类比学习
		6. 反比例函数移到二次函数后，内容安排更加紧凑，便于类比学习，**掌握研究函数的一般思想与方法**
		7. ![[Pasted image 20260818233906.png]]
4. 图形与几何
	1. 整体上，从简单到复杂的主线安排，图形变化与图形与坐标穿插其中，图形变化强调从运动变化的观点来研究图形，**理解变化时的规律和变化中的不变量**，图形与坐标强调**数形结合，用代数方法研究图形，用坐标法分析和解决实际问题**
	2. 具体地
		1. 直线形→曲线形→直线形和曲线形结合，从一般到特殊认识三角形和四边形
		2. 平行四边形改为四边形，更好的体现从一般到特殊的研究过程
		3. 圆一章拆分为圆和直线与圆的位置关系两章
		4. 图形的变化
		5. ![[Pasted image 20260818234945.png]]
	3. 关于推理与证明
		1. 认识图形、研究图形性质过程中，引导学生理解欧几里得平面几何的基本思想，感悟几何体系基本框架
		2. 按照“说理”“简单推理”“用符号表述推理”循序渐进培养推理能力
		3. 公理化方法数学史
	4. 关于尺规作图
		1. 增加“**过直线外一点作直线的平行线**”、“**过圆外一点作圆的切线**”**
		2. 重视尺规作图的产生思路，例如**作一个角等于已知角**的尺规作图方法——利用三角形全等
		3. 学习图形的有关性质后，进一步利用图形的性质进行尺规作图，例如**利用菱形的性质得到作角平分线**——利用菱形性质“**作一条线段的垂直平分线**”、“**过直线外一点作已知直线的垂线**”
5. 统计与概率
	1.  统计内容强调从实际问题出发，经历数据收集、整理、描述、分析。。。，体会抽样的**必要性**和数据分析的**合理性**
	2. 概率内容强调经历简单随机实践发生概率的计算过程，尝试用概率**定量描述**随机现象发生的可能性大小，理解概率的意义
	3. 具体内容处理时，发挥**典型案例**作用，让学生经历具有探究性和活动性的收集、整理、描述、分析数据的**统计过程**，发展学生的数据观念
6. 综合与实践
	1. 加强课程综合，注重关联（跨学科主题学习活动）
	2. 变革育人方式，突出实践
	3. 课标的要求：“三会”
	4. 关键特征：综合性、实践性、开放性
	5. ![[Pasted image 20260822161609.png]]
#### 教科书的组织形式与呈现方式
![[Pasted image 20260822164441.png]]

 1. 提高例题、习题的**针对性、有效性、创新性、层次性、精确性**，形成一个立体化的能力培养系统。
 2. 习题、复习题按题目教学功能分为“**复习巩固**”、“**综合运用**”、“**拓广探索**”三个层次
 3. 适当设置"**阅读与思考**"、"**观察与猜想**"、"**探究与发现**"、"**信息技术应用**"等选学内容
 4. 每章安排小结：本章知识结构、回顾与思考
 5. 每章安排1~2个是数学活动，每册设置2个综合与实践活动，综合实践活动选题要体现综合性、与现实生活的联系性、活动的操作性和实践性，跨学科的综合性，问题解决的开放性和拓展性
 6. 加强数学文化在教科书中的渗透。在正文中设置“**溯源**”栏目，设置“**图说数学史**”的选学内容
#### 教科书编写思路
##### （一）坚持德育为先，落实全面育人，体现教材的价值观
1. 2018年9月：全国教育大会，总书记关于教材的论述:**教材是国家事权，数学无国界，数学教材有国界**
2. 2022年10月：二十大报告写入“**加强教材建设与管理**”
##### （二）聚焦核心素养、发展理性思维，体现教材的思想性
1. 理性思维、科学精神、促进个人智力发展
2. 注重学习内容的结构化，加深数学的**整体性**认识
3. 关注数学知识所蕴含的**数学思想、通性通法**
##### （三）面向全体学生、关注发展差异，体现教材的发展性
##### （四）加强问题引导、展现思维过程、体现教材的过程性
##### （五）重视背景应用、加强综合实践，体现教材的联系性
1. 数学概念的引入，要强调现实背景，回归内容的本质
2. 应用数学解决问题
3. 纵向联系、横向联系
##### （六）改进呈现方式、提升学习体验、体现教材的适切性
##### （七）精选主题素材、创新融入方式、体现教材的文化性
##### （八）整合信息技术、改进教学方式、体现教材的融合性
1. 课标：促进信息技术与数学课程融合
2. 利用信息技术进行复杂计算和绘图、提高学习效率
3. 动态演示数学对象和关系的变化，帮助理解对象的本质
4. 利用信息技术建立呈现探究环境，帮助分析和解决问题
