# 爬虫Referer策略分析

## 核心概念

- 关于请求头里Referer怎么填绕过反爬  
    - 如果需要爬取多个不同来源页的图片，则Referer有以下几种填写方法  
        - 填网站主页或作品模块首页  
        - 填一个该网站作品列表的某一个通用页面，比如第1页，或者一个代表性的列表页  
        - 动态设置Referer

## 为什么重要

- 填网站主页或作品模块首页，这种方式不一定能绕过反爬，效果可能不如具体页面好  
- 动态设置Referer，这样做是最贴近真实用户行为的，也是最不容易被反爬识别的，但是需要增加爬虫流程，修改代码

## 如何应用

- 浏览器打开网页  
- 按 F12 打开开发者工具 → Network（网络）标签 → 刷新页面 → 找到该图片的请求 → 查看它的 Request Headers，里面通常就有 Referer，你可以直接抄过来用。  
- 如果需要爬取多个不同来源页的图片，则Referer有以下几种填写方法  
    - 填网站主页或作品模块首页，这种方式不一定能绕过反爬，效果可能不如具体页面好  
    - 填一个该网站作品列表的某一个通用页面，比如第1页，或者一个代表性的列表页  
    - 动态设置Referer，这样做是最贴近真实用户行为的，也是最不容易被反爬识别的，但是需要增加爬虫流程，修改代码
