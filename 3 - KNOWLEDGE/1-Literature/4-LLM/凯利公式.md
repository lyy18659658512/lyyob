# 凯利公式

## 对话背景

本对话围绕凯利公式（Kelly Criterion）展开系统性推导与深度追问——从经典二元赌局模型出发，经求导得最优下注比例 f* = (bp - q)/b，再逐层解释为何取对数而非直接最大化期望、为何赢输顺序不影响渐近结果、独立随机变量乘积期望的性质，最后系统梳理市面三种简化版本的推导脉络、应用实例及 μ/σ² 近似版的深层含义（与 Sharpe Ratio、Fisher 信息、扩散过程的关系）。对话 AI 为元宝（腾讯混元 Hy3 模型）。

### 1. 凯利公式推导

**用户**：凯利公式是如何推导出来的，为什么凯利公式是对的

**元宝**：凯利公式的核心思想是：在期望收益为正的赌局中，存在一个最优下注比例，使得长期资本增长率最大化，且永远不会破产。

**问题设定**：赢概率 p，赢时净赚 b 倍本金；输概率 q=1-p，亏掉全部下注。每次拿出当前资金的比例 f 下注，各次独立同分布。

**推导**：一次下注后资金乘子为 (1+bf) 或 (1-f)。N 次后，由大数定律，约赢 Np 次、输 Nq 次，资金取对数求长期增长率 G(f) = p·ln(1+bf) + q·ln(1-f)。对 f 求导置零，解得 f* = (bp - q)/b。特殊地，b=1 时 f* = p - q。

**为什么"对"**：① 最大化几何平均增长率（不是算术平均）；② 永远不会破产（f* ≤ 1 且期望为正时）；③ 优于固定金额或过度下注（下注太多波动蚕食复合增长，全押一次输即归零）；④ 与 Shannon 信息论同源——下注比例 = 优势/赔率；⑤ 大数定律保证 N→∞ 时凯利策略财富以概率 1 指数增长，任何其他固定比例严格更低。

来源：对话记录 §1

### 2. 赢输顺序为什么不影响终值

**用户**：玩N次，赢和输的顺序不是会影响最后资金W_N吗，为什么公式可以是那样

**元宝**：在比例下注模型里，每次乘子只取决于当次胜负（1+bf 或 1-f），与当前资金无关。终值 W_N 仅与总胜场数 K 有关，与胜负排列顺序无关——乘法交换律保证同一串胜负的不同排列终值完全相同。这不是假设顺序固定，而是大数定律保证 K/N → p，从而 ln(W_N)/N → G(f) 几乎必然收敛。"赢 Np 次输 Nq 次"是对所有路径典型极限的缩写，不是对某条路径的描述。

> **注意**：若改为固定金额下注（非比例），顺序确实会影响终值——但凯利原始模型是比例下注 + 独立同分布。

来源：对话记录 §2

### 3. 为什么取对数而不是直接最大化期望

**用户**：为什么凯利公式得出最终资金公式后，要左右取对数再求最值，而不直接求最值

**元宝**：直接最大化 E[W_N] 会导向全押（f=1），因为 E[W_N] = [p(1+bf) + q(1-f)]^N 关于 f 单调递增（只要期望为正）。但全押一次输即归零，长期几乎必然破产。问题出在"算术平均"骗了你——真实财富增长是乘法过程，决定长期命运的是几何平均收益率。对数把乘法变成加法：ln(W_N) = Σ ln(X_i)，最大化 E[ln(X_i)] 就是最大化长期几何增长率。

**对数不是技巧，是公理化必然**：在"独立初始财富、长期最优、满足独立性公理"的合理假设下，对数效用是唯一能导出凯利公式的效用函数。

数值对比：设 p=0.6, b=1。全押 → E[W_N] 最大但 ln(1-f) = -∞ 导致破产概率；凯利 f*=0.2 → E[ln] 最大；保守 f=0.001 → 活得久但增长慢。

来源：对话记录 §3

### 4. 课程归属

**用户**：哪门课程里会介绍这个理论和推导

**元宝**：凯利公式不是独立课程，而是多门课的交叉点：

| 你问的问题 | 主要归属课程 |
| --- | --- |
| 赢输顺序不影响终值、大数定律怎么用 | 概率论 / 随机过程 |
| 为什么取对数不取期望金额 | 随机过程 / 信息论 / 决策论 |
| 求导 | 概率论（计算） |
| 和香农熵、信道容量的关系 | **信息论** |
| 多资产、连续收益、投资实操 | 金融数学 / 量化投资 |

教材：Cover & Thomas《Elements of Information Theory》第 6 章 "Gambling and Data Compression" 是最经典的推导出处，凯利 1956 原论文叫 *A New Interpretation of Information Rate*，将最大财富增长率与互信息等价。

自学顺序：概率论（大数定律 + 乘性过程）→ Cover & Thomas 第 6 章 → 随机过程（几乎必然收敛）→ Cover 的 Universal Portfolios 或量化课讲义。

来源：对话记录 §4

### 5. 期望资金公式的来源

**用户**：前面的期望资金公式是怎么来的

**元宝**：单次下注随机乘子 X_i 取值 (1+bf) 或 (1-f)。N 次后 W_N = W_0 · Π X_i。取期望：E[W_N] = W_0 · E[Π X_i]。关键性质——独立随机变量乘积的期望 = 期望的乘积：E[Π X_i] = Π E[X_i] = [E[X_1]]^N = [p(1+bf) + q(1-f)]^N。

这不是从"Np 次赢"凑出来的，而是从独立性严格得到的。它最大化的是算术期望，和对数增长率最大化不是一回事——前者鼓励全押，后者自动避开破产。

来源：对话记录 §5

### 6. 独立随机变量乘积期望的推广

**用户**：独立随机变量乘积的期望 = 期望的乘积。不同的独立随机变量也成立吗

**元宝**：**成立。**只要 X_i 相互独立（不需要同分布），就有 E[Π X_i] = Π E[X_i]。证明只用独立性（联合分布 = 边缘分布乘积）和期望存在（Fubini 定理），完全不涉及同分布。同分布只是让 E[X_i] 都一样从而可以合并成 N 次方；若每次赌局规则不同，独立性仍成立，乘积期望仍可拆开，只是不能合并。

> **常见误区**：独立 ⇒ 乘积期望可拆，但协方差为 0 ≠ 独立。凯利公式敢这么拆靠的是明确假设各次下注独立，不是弱条件。

来源：对话记录 §6

### 7. 市面简化版公式

**用户**：为什么市面上的凯利公式好像简化了，没有这个推导过程，简化的公式是什么

**元宝**：市面 90% 的凯利公式科普砍掉了信息论背景、大数定律证明、对数期望框架，只给代数结果。

**三种常见简化版**：

| 版本 | 公式 | 前提 |
| --- | --- | --- |
| 1:1 特例 | f* = p - q | b=1，赢输净盈亏各 1 单位 |
| Decimal odds 版 | f* = (p·D - 1)/(D - 1) | 赔率 D，赢拿回 D 元（含本金） |
| 连续近似版 | f* = μ/σ² | 小 f、近似正态、泰勒展开 |

**市面做了三刀**：① 不提对数效用/几何增长；② 只给二元特例；③ 金融市场再砍一刀（泰勒展开 μ/σ²）。完整推导链（设 W_N → 取对数 → 大数定律 → 最大化 G(f) → 求导）在实务中被压缩成一两行结论。

来源：对话记录 §7

### 8. 简化版应用实例

**用户**：举几个例子说明一下简化版的应用

**元宝**：

**例1 体育博彩**：p=55%, decimal odds=2.0 → f* = (0.55×2-1)/(2-1) = 10%。坑：你感觉的 55% 往往只有 52%，f* 直接掉一半。

**例2 股票短线**：止盈 +10%, 止损 -5%, 胜率 60% → b = 0.1/0.05 = 2 → f* = (2×0.6-0.4)/2 = 40%。坑：股票非二元结局，实战用半凯利 20%。

**例3 期货趋势策略**：年化 μ=12%, σ=20% → f* = 0.12/0.04 = 3（3 倍杠杆），半凯利约 1.5 倍。坑：收益率非正态、有跳空。

**例4 多策略组合**：各策略分别算 f*，取半凯利后做归一化得到相对仓位比例，而非绝对杠杆。

**实战原则**：永远假设自己的 p/μ 被高估了，半凯利起步，极端行情再打折。

来源：对话记录 §8

### 9. 三个简化版分别如何从完整推导得来

**用户**：上面简化版分别是如何从推导公式继续推导得来的

**元宝**：三条路径都从完整凯利最优解 f* = (bp - q)/b 出发：

- **1:1 特例 f* = p - q**：直接令 b=1，代入精确解。**没有近似，只是代特例。**
- **Decimal odds 版 f* = (p·D-1)/(D-1)**：令净赚 b = D-1，代入精确解展开。**仍是精确解，只是换变量。**
- **连续版 f* = μ/σ²**：把离散收益换为连续随机变量 r，在 f 很小时对 ln(1+f·r) 泰勒展开到二阶，取期望后近似 E[ln] ≈ μ·f - σ²·f²/2，对 f 求导得 f* = μ/σ²。**这一刀才是真简化——换模型 + 泰勒截断。**

注意：μ/σ² 不是从二元公式代数变形来的，而是换模型后重新近似。别把 μ/σ² 直接套到 p、b 参数上。

来源：对话记录 §9

### 10. μ/σ² 版的详细应用

**用户**：最后一个简化版具体如何应用呢，举例子

**元宝**：

**计算流程**：① 拿历史日收益序列 r_i → ② 算日收益均值 μ_d 和日波动 σ_d → ③ 年化 μ = μ_d×252, σ = σ_d×√252 → ④ 代入 f* = μ/σ²。

**数值例**（A 股趋势策略，3 年回测）：μ_d=0.0006, σ_d=0.012 → μ≈15%, σ≈19% → f* = 0.15/0.0361 ≈ 4.2 倍杠杆（理论）。

**为什么不能上 4 倍？** ① 近似值——真实收益有偏态、尖峰肥尾；② 估计误差——μ 被高估一点、σ 被低估一点，f* 剧烈变化；③ 回撤——f=4 时一次 10% 回撤亏 42% 本金。

**实盘做法（Fractional Kelly）**：

| 风险偏好 | 倍数 |
| --- | --- |
| 激进对冲基金 | 0.5–0.75 凯利 |
| 普通量化策略 | 0.25–0.5 凯利 |
| 个人投资者 | ≤ 0.25 凯利 |

流程：回测算 f* → 当成理论上限 → 至少打 5 折 → 按回撤容忍度微调。

来源：对话记录 §10

### 11. μ/σ² 的深层含义

**用户**：第三个简化公式说明了最佳比例是期望除以方差，为什么这么巧，期望除以方差是不是有什么隐含的含义

**元宝**：不是巧合，是对数凹性 + 泰勒展开 + 高斯矩结构的必然结果。

**数学根源**：ln(1+f·r) 泰勒展开到二阶，一阶项系数 = μ（线性收益贡献），二阶项系数 = -σ²/2（波动惩罚），最优处二者平衡 ⇒ f = μ/σ²。

**五层等价含义**：

1. **边际交换率**：分子 μ 是下注带来的漂移收益，分母 σ² 是方差惩罚（对数效用下方差直接进二阶项）。比值 = 每承受一单位波动代价换来的长期增长。
2. **Edge × 信息精度**：f* = Sharpe Ratio / σ = Edge × (1/σ²)，其中 1/σ² 是高斯变量关于 μ 的 Fisher 信息。信息精度越高，越敢按 Edge 下注。
3. **Sharpe Ratio 除以波动**：f* = (μ/σ) / σ = Sharpe/σ。同样 Sharpe，波动越小 → 凯利分数越大（凯利看绝对波动水平，不只是单位风险收益）。
4. **扩散过程漂移/扩散系数比**：几何布朗运动 dS/S = μ dt + σ dW 下，f* = μ/σ² 等价于随机控制中最优控制增益 = 漂移率/扩散方差。
5. **对数效用的必然性**：若用 |r| 做效用会得别的比例，若不取对数会得 f→∞（全押）。"除以方差"是对数效用 + 乘法过程的数学后果，不是拍脑袋定义。

直观数值：大盘股 μ=8%, σ=16% → f*≈3.1；比特币 μ=30%, σ=80% → f*≈0.47。波动平方一上来，高收益也被"打回原形"——对数增长怕的是大幅回撤，而大幅回撤由方差主导。

来源：对话记录 §11

## 关键信息点

> 从对话中提取的可复用信息，每条独立可读。

- **概念 /** **公式**：凯利公式 f* = (bp - q)/b 给出期望为正的赌局中最大化长期复合增长率的最优下注比例。b 为赢时净赔率（下 1 元赢赚 b 元），p 为胜率，q = 1-p。特殊地，b=1（赢输 1:1）时退化为 f* = p - q。
  来源：对话记录 §1

- **概念 /** **对数效用**：凯利目标是最大化 E[ln(W_N)] 而非 E[W_N]。最大化期望资金会导向全押（f=1）从而长期必破产；对数凹性自动惩罚极端损失（任何非零破产概率的 f 都会使 ln(1-f) → -∞，拉低 G(f)）。对数效用是唯一满足"独立初始财富、长期最优、独立性公理"的函数形式。
  来源：对话记录 §3

- **概念 /** **比例下注的顺序无关性**：在经典凯利模型（比例下注 + 独立同分布）中，终值 W_N 仅取决于总胜场数 K，与胜负排列顺序无关——因为每次乘子 (1+bf) 或 (1-f) 与当前资金无关，乘法交换律保证了同一串胜负的不同排列终值相同。若改为固定金额下注，顺序则会影响终值。
  来源：对话记录 §2

- **概念 /** **独立随机变量乘积的期望**：E[Π X_i] = Π E[X_i] 只需要 X_i 相互独立，**不需要同分布**。同分布的作用仅是让各 E[X_i] 相等从而合并为 N 次方，非拆分期望的必要条件。协方差为零不等于独立。
  来源：对话记录 §6

- **概念 /** **连续凯利近似 f* = μ/σ²**：将离散收益换为连续随机变量 r，对 ln(1+f·r) 在 f 很小时泰勒展开到二阶——一阶项贡献 μ·f（线性收益），二阶项贡献 -σ²·f²/2（波动惩罚），最优处 √ ⟹ f* = μ/σ²。这是近似，只在收益率近似正态、Edge 不大时可靠。
  来源：对话记录 §9, §11

- **概念 /** **μ/σ² 的五层等价含义**：① 收益边际贡献与方差惩罚的交换率；② Edge × 信息精度（1/σ² 是 Fisher 信息）；③ Sharpe Ratio / σ；④ 扩散过程漂移/扩散系数比；⑤ 对数效用 + 乘法过程的公理化必然结果。f* = μ/σ² × σ = Sharpe，即同样 Sharpe 下波动越小的资产凯利分数越大——凯利看的是绝对波动水平，非仅单位风险收益。
  来源：对话记录 §11

- **方法 /** **简化凯利公式速查**：二元赌局 → f* = (bp - q)/b；赢输 1:1 → f* = p - q；decimal odds D → f* = (p·D - 1)/(D - 1)；连续收益 → f* = μ/σ²。前两者是精确解（代特例/换变量），后者是泰勒近似（换模型 + 截断）。勿混用——别把 μ/σ² 直接套 p、b 参数。
  来源：对话记录 §7, §9

- **方法 /** **实战凯利操作流程**：① 用历史日收益序列算年化 μ 和 σ；② 代入 f* = μ/σ² 得到理论上限；③ 至少打 5 折（半凯利 f*/2 最常用）；④ 再根据最大回撤容忍度微调。个人投资者建议 ≤ 0.25 凯利。永远假设自己的 p/μ 被高估了。
  来源：对话记录 §10

- **方法 /** **Fractional Kelly 行业参考**：激进对冲基金 0.5–0.75 凯利，普通量化策略 0.25–0.5 凯利，个人投资者 ≤ 0.25 凯利。半凯利牺牲少量增长率换大幅降低回撤，在金融实操中比纯凯利更稳健。
  来源：对话记录 §8, §10

- **事实 /** **课程归属与自学路径**：凯利公式出现在概率论（大数定律例题）→ 随机过程（乘性过程渐近增长率）→ 信息论（Cover & Thomas 第 6 章 "Gambling and Data Compression"，凯利 1956 原论文证明最大财富增长率 = 互信息）→ 金融数学（Growth-optimal portfolio）→ 决策论（对数效用公理）。推荐自学顺序：概率论 → Cover & Thomas 第 6 章 → 随机过程 → 量化投资讲义。
  来源：对话记录 §4

- **事实 /** **凯利与全押的数值对比**：设 p=0.6, b=1。全押 f=1 → E[W] 最大但一次输即归零；凯利 f*=0.2 → E[ln] 最大化；保守 f=0.001 → 活得久但增长极慢。从"期望值"看全押最好，从"长期活下来并增长"看凯利最好。
  来源：对话记录 §3
