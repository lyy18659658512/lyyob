# 牛顿迭代法求平方根

## 对话背景

本对话以"牛顿迭代法为什么能算平方根"为起点，先解释开方问题转求根问题的核心思路与切线逼近的几何直觉，推导出迭代公式 xₙ₊₁ = ½(xₙ + a/xₙ) 并说明平方收敛特性；随后对比二分法探讨两种求根方法在收敛速度、稳定性和适用条件上的差异；进而辨析"化简后的迭代式为何看似不需要显式计算函数值和导数值"，揭示代数化简背后仍在使用 f 和 f' 信息的本质；最后讨论实际数值计算中的停止准则——相邻差值、函数值、相对误差和最大迭代次数的组合使用。对话 AI 为元宝（腾讯混元 Hy3 模型）。

### 1. 牛顿法为什么能算平方根

**用户**：为什么牛顿迭代法可以算平方根

**元宝**：牛顿迭代法能算平方根，本质上是因为"求 √a"可以变成一个"求方程根"的问题，而牛顿法就是解非线性方程的通用利器。

**核心思路**：求 √a（a>0）等价于求 f(x)=x²−a 的非负实根。

**几何直觉——用切线代替曲线**：在当前猜测值 xₙ 处对曲线作切线，切线与 x 轴的交点作为下一个更精确的猜测。切线方程 y = f(xₙ) + f'(xₙ)(x−xₙ)，令 y=0，解得牛顿通式 xₙ₊₁ = xₙ − f(xₙ)/f'(xₙ)。

代入 f(x)=x²−a，f'(x)=2x，得平方根迭代公式：

> xₙ₊₁ = ½(xₙ + a/xₙ)

**平方收敛**——每迭代一次，有效位数约翻一倍。误差分析得 εₙ₊₁ ≈ εₙ²/(2√a)。求 √2，x₀=1：3 步即达 1.4142（4 位精度）。

**初值要求**：只要 x₀ > 0 就保证收敛到 √a（凸函数单调逼近），取 x₀=a 或 1 均安全。x₀ 为负则收敛到 −√a，x₀=0 则除零错误。

> 现代 CPU 的硬件平方根指令底层很多用了这个算法的变种——只需加减乘除，收敛飞快，非常适合硬件实现。

### 2. 牛顿法与二分法的对比

**用户**：牛顿迭代法和二分法是不是一样

**元宝**：不一样，是两种完全不同的求根思路。

**二分法**——靠"缩小包围圈"：利用介值定理，f(a)·f(b)<0 保证区间内必有根。每次取中点 c=(a+b)/2，判断 f(c) 符号，丢弃一半区间。本质是"排除法"。

**牛顿法**——靠"切线逼近"：在当前点作切线，用切线与 x 轴交点作为下一猜测。本质是"用线性函数局部近似非线性函数"。

**收敛速度天壤之别**：

| 方法 | 收敛阶 | 直观感受 |
| --- | --- | --- |
| 二分法 | 线性收敛（1 阶），误差每次 ×½ | 稳但慢，每步多得约 1 位有效数字 |
| 牛顿法 | 平方收敛（2 阶），误差平方级缩小 | 极快，每步有效位数约翻倍 |

以 √2 为例：二分法从 [1,2] 起约需 10 步达 4 位精度；牛顿法从 x₀=1 起只需 3 步。

**其他差异**：

| 维度 | 二分法 | 牛顿法 |
| --- | --- | --- |
| 区间/初值要求 | 必须 f(a)·f(b)<0 | 只需一个猜测 x₀，但要"够近" |
| 是否需要导数 | 不需要 | 必须知道 f'(x) |
| 稳定性 | 绝对稳定，100% 收敛 | 可能震荡、发散 |
| 单次代价 | 1 次函数求值 | 1 次函数 + 1 次导数求值 |

**比喻**：二分法像"猜数字游戏"——"大于 50？小于 50？"一步步缩小范围，笨但可靠。牛顿法像"神射手"——利用斜率信息"瞄准"根，一击即中，但瞄错了就可能脱靶。

**工业级做法**：常将两者结合——先用二分法定大范围，再用牛顿法精修；或用牛顿下山法增加稳定性。

### 3. 化简后的公式为何看似无需函数值和导数值

**用户**：牛顿法为什么每次需要一次函数求值+一次导数求值，前面讨论的例子中化简后好像无需求函数值和导数值，是不是因为求平方根函数比较特殊

**元宝**：是的，求平方根这个例子比较特殊——"函数值"和"导数值"依然被计算了，只是被"隐藏"在化简后的简洁公式里。

**拆解"隐藏的计算"**：对 f(x)=x²−a，牛顿通式 xₙ₊₁ = xₙ − (xₙ²−a)/(2xₙ)。代数化简：
- f(xₙ) = xₙ²−a 与分母约化为 a/xₙ → **被代数消掉了**
- f'(xₙ) = 2xₙ → **被吸收进了系数 ½**

最终公式 xₙ₊₁ = ½(xₙ + a/xₙ) 中 f 和 f' 不再显式出现，但本质上数学家已提前把计算过程"预消化"了。

**为什么平方根特殊**——f(x)=x²−a 太简单：

| 特性 | f(x) = x²−a | 一般函数 f(x) |
| --- | --- | --- |
| f(xₙ) | xₙ²−a（简单多项式） | sin(xₙ)+ln(xₙ)−3 等 |
| f'(x) | 2xₙ（解析表达式） | 可能需数值差分 |
| 能否代数化简 | ✅ 得到 xₙ₊₁=½(xₙ+a/xₙ) | ❌ 通常不行 |

**代码对比**——未化简版（通用）vs 化简版（平方根专用）完全等价，只是化简版更高效（省一次乘法、一次减法）。

**导数求不出来的替代方案**：
- **数值微分**：用 (f(xₙ+h)−f(xₙ))/h 近似导数，需 2 次函数求值
- **割线法**：用前两次迭代的函数值构造差商，每次仅需 1 次函数求值，收敛约 1.618 阶（介于二分法和牛顿法之间）

### 4. 迭代到什么时候停止？

**用户**：牛顿迭代法一直会迭代到什么时候停止呢？

**元宝**：理论上根往往是无理数，永远算不到"精确等于"，实际必须设定停止准则。

**五大常用准则**：

**① 相邻差值 |xₙ₊₁ − xₙ| < ε（最常用 ⭐）**
最近两步结果几乎没变化，说明已收敛。ε 如 10⁻¹⁰。

**② 函数值 |f(xₙ)| < ε**
当前 xₙ 已让 f(xₙ)≈0。对平方根：检查 |xₙ²−a| < ε。

**③ 相对误差 |xₙ₊₁ − xₙ|/|xₙ₊₁| < ε**
根大小尺度变化大时用（根接近 0 太严，根很大又太松）。

**④ 最大迭代次数 max_iter（安全网 🛡️）**
牛顿法并非总收敛——可能震荡、发散、收敛到错误根。无保护可能死循环。通常设 100。

**⑤ 组合准则（工业级）**：差值 + 函数值 + 最大迭代次数三者并用。

**√2 完整迭代轨迹**（ε=10⁻⁶）：

| 迭代 | xₙ | |xₙ−xₙ₋₁| |
| --- | --- | --- |
| x₀ | 1.0 | — |
| x₁ | 1.5 | 0.5 > ε |
| x₂ | 1.416667 | 0.0833 > ε |
| x₃ | 1.414216 | 0.00245 > ε |
| x₄ | 1.414214 | 0.000002 < ε，停止！ |

ε=10⁻⁶ 仅需 4 次；ε=10⁻¹⁵（双精度极限）约 6–7 次。

**边界情况**：当 |xₙ₊₁−xₙ| 小到被浮点精度吞没出现"机器零"时，迭代自然停止，这本身也是一种隐式停止准则。

> 数值计算的核心是"近似"而非"精确"——在浮点数体系里，连 0.1+0.2 都不等于 0.3，我们本来就必须和误差共处。

- **概念 /** **牛顿法 vs 二分法（五维对比）**：① 原理：二分法基于介值定理缩小含根区间；牛顿法基于切线线性近似逼近根。② 收敛：线性 vs 平方。③ 初始条件：需 f(a)·f(b)<0 vs 只需一个猜测但须够近。④ 是否需要导数：否 vs 是。⑤ 稳定性：绝对收敛 vs 可能震荡/发散。比喻：二分法是"猜数字游戏"（笨但可靠），牛顿法是"神射手"（快但需瞄得准）。

- **概念 /** **牛顿公式的代数化简与隐藏计算**：对 f(x)=x²−a，f(xₙ)=xₙ²−a 代入通式后被代数消去，f'(xₙ)=2x 被吸收进系数 ½，得到 xₙ₊₁ = ½(xₙ + a/xₙ)。但本质上每次迭代仍在使用 f 和 f' 的信息——只是数学家提前"预消化"了计算过程。对一般复杂函数（如 sin(x)+ln(x)−3）无法化简，必须每次显式计算 f(xₙ) 和 f'(xₙ)。

- **概念 /** **导数不可求时的替代方法**：数值微分用 (f(xₙ+h)−f(xₙ))/h 近似 f'(xₙ)，每次需 2 次函数求值；割线法用前两次迭代的函数值构造差商近似导数，每次仅 1 次函数求值，收敛约 1.618 阶（超线性，介于二分法的 1 阶与牛顿法的 2 阶之间）。

- **方法 /** **牛顿迭代停止准则（四种）**：① |xₙ₊₁−xₙ| < ε——相邻差值，最常用，ε 如 10⁻¹⁰；② |f(xₙ)| < ε——函数值直接衡量根的质量；③ |xₙ₊₁−xₙ|/|xₙ₊₁| < ε——相对误差，根大小不确定时用；④ max_iter 上限——防止震荡、发散导致死循环（必备安全网）。工业级做法组合多项，如差值+函数值+最大迭代次数。

- **方法 /** **工业级求根策略**：先用二分法粗定范围（稳），再用牛顿法精修（快），或用牛顿下山法增加稳定性。对于平方根这种简单函数，可直接用牛顿法——5–10 次迭代即达双精度浮点极限（ε=10⁻¹⁵）。
  来源：对话记录 §2, §4

- **事实 /** **平方根算法的硬件地位**：现代 CPU 硬件平方根指令（如 x86 的 FSQRT）底层多基于牛顿法或其变种，因该算法仅需加减乘除（无复杂函数调用）、平方收敛极快（5–10 次达极限精度），非常适合硬件微码实现。
  来源：对话记录 §1, §4

- **事实 /** **浮点机器零作为隐式停止**：当 |xₙ₊₁−xₙ| 小到被浮点精度吞没时，xₙ₊₁ 在机器表示中等于 xₙ，迭代自然停止——这本身就是一种隐式停止准则，独立于显式容差判断。
