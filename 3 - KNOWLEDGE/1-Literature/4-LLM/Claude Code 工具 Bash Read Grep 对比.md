# Claude Code 工具 Bash Read Grep 对比

## 对话背景

本笔记整理自元宝AI对话（2026-06-09），对比了 bash/read/grep 三个工具的基本概念和层级关系，并进一步探讨了在 Claude Code / Claudian 体系中 Bash、Read、Grep 作为 Agent 内置工具的专属职责、选择决策树与权限模型。

## 精选对话记录

### 1. bash、read、grep 的基本区别

**用户**：bash 和 read grep 区别

**LLM**：它们属于三个不同层级的工具：

- **bash**：Shell 解释器/命令行环境，提供运行命令、执行脚本的平台。是你输入命令的地方，管理进程、变量、流程控制等。
- **read**：bash 的内置命令，从标准输入（键盘、文件、管道）读取一行数据并存储到变量中。主要用于交互式输入和脚本中获取用户输入。
- **grep**：独立的外部程序/工具，在文本中搜索匹配模式（正则表达式）。不是 bash 内置的，但通常系统都会安装。

| 项目 | bash | read | grep |
|------|------|------|------|
| 性质 | Shell 解释器/环境 | bash 内置命令 | 独立的外部程序 |
| 主要用途 | 执行命令、运行脚本 | 读取用户输入 | 文本搜索过滤 |
| 是否内置 | 本身是解释器 | 是 bash 的一部分 | 否，需额外安装 |
| 典型场景 | 写脚本、执行命令 | 脚本中交互获取输入 | 查找日志、过滤输出 |

**一句话总结**：bash 是"舞台"（运行环境），read 是"麦克风"（接收输入），grep 是"搜索引擎"（查找内容）。

### 2. Claude Code 中的 Bash、Read、Grep 工具

**用户**：在 Claudian 使用过程中三者区别

**LLM**：在 Claudian（底层跑的是 Claude Code CLI）中，Bash、Read、Grep 不是传统 shell 意义上的命令，而是 **Claude Code Agent 的三个内置工具（Built-in Tools）**，各有各的专属职责：

**📖 Read — 读文件内容**
- 将指定文件（或某几行）读进来给 Claude 看
- 类比：安全的 `cat`，但带行号、可指定偏移量、有截断保护
- 权限：**只读，不需要你授权**

**🔍 Grep — 按内容搜代码**
- 在整个代码库里按正则/关键字搜索匹配行（底层是 ripgrep，很快）
- 类比：安全的 `grep -r`，但输出格式受控、可省 token
- 权限：**只读，不需要你授权**
- 典型场景：找函数在哪被调用、搜索所有 TODO/FIXME、搜变量定义和使用位置
- 关键约束：Claude Code 规定——**能用 Grep 工具就别自己 Bash 里跑 `grep -r`**

**⚡ Bash — 执行任意 Shell 命令**
- 真正在终端里跑命令——构建、测试、git、安装依赖、管道组合等
- 类比：就是你平时在终端敲的那些东西，但经过一层**权限闸门**
- 权限：**需要你确认**（因为它能干几乎任何事）

**选择决策树**：

| 你要做的事 | 用哪个工具 |
|-----------|-----------|
| 找"哪些文件叫 *.ts" | → Glob（不在三工具内但常配合） |
| 搜"代码里哪行出现了某关键词/函数名" | → **Grep** ✅（最快、最省 token，只读安全） |
| 已经知道是哪个文件，想看里面写了啥 | → **Read** ✅（支持 offset/limit 读局部最好） |
| 要跑构建/测试/git/安装/任何系统级操作 | → **Bash** ✅（唯一正确的选择） |

**反模式**（Claude Code 会尽量避免）：
- 用 Bash("cat file.ts") → 应改用 Read
- 用 Bash("grep -r pattern .") → 应改用 Grep
- 用 Bash("find . -name '*.ts'") → 应改用 Glob

| 工具 | 一句话 | 危险等级 |
|------|--------|---------|
| Grep | "告诉我哪里有这个内容" — 搜索哨兵 | 🟢 安全 |
| Read | "把这个文件给我看看" — 眼睛 | 🟢 安全 |
| Bash | "去替我执行命令" — 手 | 🔴 需要你点头 |

## 关键信息点

- **概念/** **bash**：Shell 解释器/命令行环境，提供运行命令和执行脚本的平台。不是具体的命令而是运行环境（舞台）。
  来源：对话记录 §1

- **概念/** **read 命令**：bash 内置命令，从标准输入读取一行数据并存入变量。主要用于交互输入和脚本中从管道读取数据。
  来源：对话记录 §1

- **概念/** **grep 命令**：独立的外部文本搜索工具，支持正则表达式匹配。不是 bash 内置，但通常系统默认安装。
  来源：对话记录 §1

- **概念/** **Claude Code 的 Read 工具**：Agent 内置的只读文件读取工具。支持指定行号偏移和截取范围。无需用户授权。
  来源：对话记录 §2

- **概念/** **Claude Code 的 Grep 工具**：Agent 内置的只读搜索工具（底层 ripgrep），按正则/关键字搜索代码。比在 Bash 中手动跑 grep 更省 token、更安全。无需用户授权。
  来源：对话记录 §2

- **概念/** **Claude Code 的 Bash 工具**：Agent 中执行任意 Shell 命令的工具，可做构建、测试、git、安装等操作。需要用户逐条授权确认。
  来源：对话记录 §2

- **方法/** **Claude Code 工具选择决策树**：搜索内容用 Grep → 读取文件用 Read → 执行操作用 Bash。避免用 Bash 替代 Read 或 Grep 的"反模式"。
  来源：对话记录 §2
