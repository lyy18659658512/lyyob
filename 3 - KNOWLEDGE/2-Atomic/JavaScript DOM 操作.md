## JavaScript DOM 操作
DOM（文档对象模型，Document Object Model）是 HTML 文档的编程接口，它将网页中的所有元素表示为一个树状结构。JavaScript 通过操作 DOM 来让交互结果显示在浏览器上
## 操作步骤  
1. 选择元素：通过 DOM API 找到需要操作的元素。  
2. 修改内容或样式：通过修改元素的属性（如 innerHTML、style 等）来改变页容。  
3. 监听事件：通过事件监听器捕获用户的操作。  
4. 更新页面：根据用户的操作动态更新 DOM，浏览器会自动重新渲染页面。  
简单来说，JavaScript 就像一个"桥梁"，它连接了用户的操作和页面的变化，使得网页可以变得动态和交互性强。
