> [!summary]- 📊 项目统计
> ```dataview
> TABLE length(filter(rows, (r) => r.status = "active")) AS "🔥 进行中", length(filter(rows, (r) => r.status = "ongoing")) AS "🌱 持续", length(filter(rows, (r) => r.status = "someday")) AS "⏳ 孵化", length(rows) AS "📁 总计"
