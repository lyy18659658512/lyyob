# 🏠 我的知识库 · 看板

## ⏰ 今日待办

```dataview
TASK
FROM "1 - JOURNAL"
WHERE file.day = date(today) AND !completed
```

> [!danger]- 📋 历史待办（今日之前未完成）
> ```dataview
> TABLE WITHOUT ID
> choice(length(rows) > 0, "📋 共 " + length(rows) + " 条待办未完成", "🎉 历史待办已清零") AS ""
> FROM "1 - JOURNAL"
> WHERE file.day < date(today)
> FLATTEN file.tasks AS task
> WHERE !task.completed
> GROUP BY ""
> ```
>
> ```dataview
> TASK
> FROM "1 - JOURNAL"
> WHERE file.day < date(today) AND !completed
> SORT file.day DESC
> ```

## 💼 行动看板

> [!summary]- 📊 项目统计
> ```dataview
> TABLE length(filter(rows, (r) => r.status = "active")) AS "🔥 进行中", length(filter(rows, (r) => r.status = "ongoing")) AS "🌱 持续", length(filter(rows, (r) => r.status = "someday")) AS "⏳ 孵化", length(rows) AS "📁 总计"
> FROM "2 - ACTION"
> WHERE type = "project" AND status != "done"
> GROUP BY " "
> ```

> [!note]+ 🔥 1-Career · 事业
> ```dataview
> TABLE choice(progress = "0%", "🔴", choice(progress = "100%", "✅", choice(progress, "🟩 " + progress, "♾️"))) AS "进度", choice(status = "active", "🔥 进行中", choice(status = "ongoing", "🌱 持续", "⏳ 孵化")) AS "状态", deadline AS "截止"
> FROM "2 - ACTION/1-Career"
> WHERE type = "project" AND status != "done"
> SORT choice(status = "active", 1, choice(status = "ongoing", 2, 3)) ASC, deadline ASC
> ```
