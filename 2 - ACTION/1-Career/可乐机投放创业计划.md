# 可乐机投放创业计划

## 📋 项目概述

### 商业模式
```
抖音短视频获客 → 微信私聊成交 → 可乐机投放 → 糖浆耗材持续复购
```

- **产品**：可乐机（冰饮机）+ CO₂气瓶 + 糖浆，投放至餐饮/商业场所
- **获客**：通过抖音短视频（同城流量 + 行业垂直内容）精准引流
- **成交**：引流至微信，私域沟通、报价、签约
- **盈利**：机器差价/押金 + 糖浆与CO₂耗材长期复购（核心利润）
- **状态**：从零起步，一人公司
- **供应模式**：朋友自有工厂（已实地考察），我作为分销商拿货
- **优势**：无中间商、价格可控、售后可直接对接工厂、样品支持方便

### 核心指标（KPI）

| 指标 | 短期目标（1-3月） | 中期目标（3-6月） | 长期目标（6-12月） |
|------|------------------|------------------|------------------|
| 抖音粉丝 | 1000+ | 5000+ | 2万+ |
| 月均视频发布 | 30条（日更） | 60条（日更2条） | 90条（日更3条） |
| 月均微信咨询 | 30+ | 100+ | 300+ |
| 月均成交 | 3-5台 | 10-15台 | 30+台 |
| 月复购收入 | — | 2000+ | 1万+ |
| 月净利润 | — | 5000+ | 3万+ |

## 📚 学习路线图

按优先级排列，打勾表示已完成：

### 🟢 第一阶段：MVP 快速验证（第1-2周）← 当前所处阶段

核心思路：先发视频看市场反馈，有问题再来深挖细节，不要"准备好了再出发"

- [ ] **1.1 抖音账号搭建（最快半天搞完）**
  - 账号定位：简单直接（如「可乐机老张」「XX市饮料机投放」）
  - 头像/简介/背景图弄好
  - 养号：刷几天同城+同行视频
- [ ] **1.2 第一条视频快速产出**
  - 不需要剪辑多精，手机拍+剪映简单剪+加字幕即可
  - 选题参考：直接拍机器出饮料的过程 + 配一段简单介绍
  - 发布时带同城定位
- [ ] **1.3 边做边补（有反馈了再深挖）**

> ⏸️ **以下内容暂跳过**，等视频有流量/有客户咨询了再回头补：

| 跳过项 | 什么时候补 |
|--------|-----------|
| 产品完整参数/型号对比 | 客户问具体型号时 |
| 糖浆成本精确核算 | 客户问价格时 |
| 价格体系/押金方案 | 准备成交第一单前 |
| 故障维修学习 | 安装第一台机器前 |
| 工厂实操装样机 | 同上 |
| 竞品完整调研 | 视频方向不确定时 |

### 🟡 第二阶段：短视频内容创作（第3-6周）

目标：具备独立制作优质短视频的能力

- [ ] **2.1 抖音账号搭建**
  - 账号定位：名字 + 头像 + 简介（突出专业/靠谱）
  - 账号装修：背景图、商家页面、联系方式设置
  - 蓝V认证（视情况开通）
  - 养号期：前7天正常刷同城、同行视频，模拟真人行为
- [ ] **2.2 拍摄技能**
  - 手机拍摄基础：光线、构图、稳定（手机支架）
  - 拍摄场景：开店过程、机器实拍、客户现场、使用教学
  - 出镜训练（可选）：口播基础、镜头感、表达力
  - **工具清单**：手机支架、补光灯、无线麦克风（入门200-500元搞定）
- [ ] **2.3 剪辑技能（剪映）**
  - 基础操作：切割、转场、变速、字幕
  - 音频处理：背景音乐、音量平衡、音效
  - 封面制作：吸引眼球的封面标题
  - 进阶：关键帧、画中画、蒙版（用不上先跳过）
  - 学习资源：B站搜索「剪映新手教程」即可
- [ ] **2.4 选题与文案**
  - 爆款公式：痛点 + 解决方案 + 成果展示
  - 选题方向：
    - 🔥 科普类：「为什么炸鸡店都在用可乐机？」
    - 🔥 揭秘类：「可乐机一杯饮料成本只要3毛钱」
    - 🔥 反差类：「白送一台机器，赚什么钱？」
    - 🔥 案例类：「刚给XX店装了一台，老板笑开花」
    - 🔥 对比类：「堂食店vs没饮料店，营业额差多少」
    - 🔥 痛点类：「顾客想喝可乐，你说没有？」
  - 标题与文案技巧：前三秒决定完播率
  - 建立选题库：每天收集3条同行爆款，拆解套路

### 🟠 第三阶段：获客与转化（第4-10周，与第二阶段重叠并行）

目标：从视频播放到微信成交的完整闭环跑通

- [ ] **3.1 抖音引流机制**
  - 同城流量：发布时带位置定位
  - 抖音SEO：标题关键词布局（如「XX市可乐机投放」）
  - 引导动作：评论区引导、私信自动回复设置
  - 主页设置：联系方式引导、企业微信配置
- [ ] **3.2 微信私域承接**
  - 微信人设：行业顾问、专业靠谱、不催不扰
  - 朋友圈运营：每天1-2条（不刷屏、有价值）
    - 内容：安装案例、客户反馈、行业知识、生活日常
  - 微信沟通SOP：
    1. 破冰：确认需求 + 了解门店情况
    2. 科普：介绍方案 + 产品价值
    3. 算账：帮客户算能赚多少钱
    4. 解除疑虑：维护谁负责？坏了怎么办？
    5. 促成：限定方案/赠品/限时优惠
- [ ] **3.3 销售话术与异议处理**
  - 常见异议：
    - 「机子坏了谁修？」→ 定期上门维护，快速响应
    - 「糖浆会不会很贵？」→ 算账对比（vs瓶装可乐利润）
    - 「我没地方放」→ 台面式不占地方，尺寸数据
    - 「之前没人喝饮料」→ 有饮料能带动主食品类
    - 「免费投放有什么套路？」→ 坦诚说明耗材模式
  - 报价方案设计：
    - 方案A：押金xxx元，机器用满1年退押金，糖浆按进货价供应
    - 方案B：无押金，每月保底采购xxx元糖浆
    - 方案C：买断机器xxx元，糖浆优惠价供应
- [ ] **3.4 代理/BD拓展（可选进阶）**
  - 找本地地推人员合作分佣
  - 联系餐饮设备经销商代推

### 🔴 第四阶段：交付与运营（第6周起持续）

目标：客户满意、持续复购、口碑裂变

- [ ] **4.1 安装与交付服务**
  - 安装标准流程：验机 → 安装 → 调试 → 教学
  - 给客户的操作手册（打印或电子版）
  - 首次糖浆配送 + 后续自动补货提醒
- [ ] **4.2 售后服务**
  - 定期巡检：每月/每季度上门检查清洗
  - 故障响应：24小时内响应，48小时内到场
  - 建立客户微信群：有问题随时沟通
  - 备机策略：准备1-2台备用机，紧急时替换
- [ ] **4.3 耗材复购管理**
  - 建立客户耗材消耗台账
  - 自动补货提醒（预估喝完前3天联系客户）
  - 批量采购降低糖浆成本
  - 节假日促销：买10箱送1箱等
- [ ] **4.4 口碑与裂变**
  - 客户见证视频（客户出镜说效果）
  - 老客户转介绍激励：介绍成功送糖浆/返现金
  - 案例库建设：每个客户拍Before/After

## 🎯 核心决策节点

两周期限，根据视频反馈决定下一步：

```
第1-2周：先发10条视频看看反应
           │
      ┌────┴────┐
      ↓         ↓
  有流量/咨询    完全没反响
      │         │
  ↓ 深入产品   ↓ 调整内容方向
  报价方案   换选题/换形式/真人出镜
  尝试成交    再试2周
              │
         ┌────┴────┐
         有起色     还是没反应
          │         │
      继续放大   换赛道/反思产品定位
```

> ⚡ **核心原则**：不花超过2周准备，先丢到市场上看真实反馈，用反馈指导下一步。

| 风险 | 概率 | 应对方案 |
|------|------|---------|
| 视频没流量 | 高 | 坚持日更 + 边做边优化选题 + 真人出镜提升信任 |
| 客户不信任新号 | 中 | 持续输出专业内容 + 有工厂背书 + 免费试装/押金可退 |
| 机器故障/售后麻烦 | 中 | 选可靠机器品牌 + 备机 + 定期巡检 |
| 糖浆供应链断供 | 低 | 至少2家供应商备选 + 适当备库存 |
| 季节性波动 | 中 | 夏季旺季全力冲量，冬季推热饮机或室内场景 |
| 客户拖欠糖浆款 | 低 | 签约明确结算周期，押金制兜底 |

## 🏭 工厂直供优势（如何用好这个资源）

你的朋友工厂是你最大的差异化武器，比别人多了几个关键优势：

| 优势 | 怎么利用 |
|------|---------|
| **价格优势** | 没有中间商，拿货价更低，可以打价格战或留更高利润 |
| **售后保障** | 客户问"坏了怎么办"，你可以直接说"工厂直接对接"，比二道贩子有说服力 |
| **样机支持** | 随时借样机拍视频、给客户展示，零成本 |
| **定制空间** | 后期可以在机器上贴自己的品牌/联系方式，建立品牌 |
| **内容素材** | 工厂生产线也是绝佳的视频素材（实拍工厂=信任感） |
| **知识赋能** | 直接从工厂学技术，你比同行更专业 |

> 💡 **建议**：可以去工厂拍一条视频，展示生产流程——"我的可乐机直接从工厂拿货"本身就是很好的内容。
