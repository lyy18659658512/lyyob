## Obsidian 教程

![](https://www.runoob.com/wp-content/uploads/2026/05/obsidian.png)

Obsidian 是一款基于 Markdown 文件的个人知识库与笔记管理工具，主要用于知识整理、笔记记录和构建个人知识体系。

Obsidian 采用本地文件存储方式，所有笔记都以普通 Markdown 文档形式保存，便于迁移、备份和长期管理。

Obsidian 和传统笔记软件最大的区别不是能记笔记，而是它把笔记变成一个可连接、可扩展、可计算的知识网络。

## 为什么使用 Obsidian

大部分人在学习过程中都会遇到一个问题：学过很多东西，但过段时间就忘了，或者知道记过，却找不到。

普通笔记软件通常只是信息仓库，而 Obsidian 更像知识中枢。

Obsidian 的核心思想是： **把零散的笔记连接起来，让知识自己长出来。**

### Obsidian 能带来什么

| 能力 | 说明 |
| --- | --- |
| 知识关联 | 通过双向链接自动建立知识之间的关系 |
| 本地存储 | 所有笔记都是普通 Markdown 文件，不依赖云数据库 |
| 知识图谱 | 自动生成知识关系网络图 |
| 插件扩展 | 支持日历、任务管理、AI、Git、思维导图等插件 |
| 跨平台 | 支持 Windows、macOS、Linux、Android 和 iOS |

### 普通笔记软件常见问题

很多人记录大量内容后都会出现：

- 收藏了很多文章，却找不到。
- 知识点越来越多，越来越乱。
- 重复记录相同内容。
- 写过的东西无法再次利用。
- 笔记越来越多，但知识没有增长。

Obsidian 的目标不是让你写更多，而是让你连接更多。

## 适合什么人学习

Obsidian 并不是所有人都需要，它更适合长期积累和持续学习的人。

| 用户类型 | 适用场景 |
| --- | --- |
| 程序员 | 技术笔记、代码片段、项目文档 |
| 学生 | 课程整理、考研、知识复习 |
| 写作者 | 素材管理、文章创作、灵感收集 |
| 研究人员 | 论文管理、资料整理 |
| 重度学习者 | 建立长期个人知识库 |

### 不太适合的人

- 只想记录临时事项。
- 只写待办事项。
- 不喜欢配置软件。
- 希望多人实时协作。

如果只是简单记录：

```
今天买菜
下午开会
周末聚餐
```

使用普通便签工具可能更加直接。
