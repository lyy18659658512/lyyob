### 核心区别（层级关系）

可以把它们看作三个不同层级的工具：

1. 1.

3. 3.
	**grep** - 一个独立的 **文本处理工具**

### 1\. bash

- •
	**是什么** ：一个 **Shell解释器/命令行环境**
- •
	**作用** ：提供运行命令、执行脚本的平台
- •
	**特点** ：
	- •
		你输入命令的地方
		- •
		解释和执行你写的脚本
		- •
		管理进程、变量、流程控制等
```bash
bash# 你首先要进入bash环境，然后才能使用其他命令
$ bash
# 或者在脚本开头声明
#!/bin/bash
```

### 2\. read

- •
	**是什么** ：bash的 **内置命令**
- •
	**作用** ：从标准输入（键盘、文件、管道） **读取一行数据** ，并存储到变量中
- •
	**特点** ：
	- •
		主要用于交互式输入
		- •
		常用于脚本中获取用户输入
		- •
		是bash自带的，无需额外安装
```bash
bash# 示例1：读取用户输入
read -p "请输入你的名字：" name
echo "你好, $name!"

# 示例2：从管道读取
echo "line1" | read var
```

### 3\. grep

- •
	**是什么** ：一个 **外部程序/工具**
- •
	**作用** ：在文本中 **搜索匹配模式** （正则表达式）
- •
	**特点** ：
	- •
		强大的文本搜索工具
		- •
		不是bash内置的，但通常系统都会安装
		- •
		主要用于过滤和查找
```bash
bash# 示例1：在文件中搜索
grep "error" log.txt

# 示例2：结合管道
cat file.txt | grep "pattern"
```

### 实际使用中的关系

它们经常 **组合使用** ：

```bash
bash#!/bin/bash
# 这个例子展示了三者的协作

# 1. bash 环境运行脚本
# 2. read 获取用户输入
read -p "请输入搜索关键词: " keyword

# 3. grep 在文件中搜索
grep "$keyword" data.txt

# 或者更常见的管道组合
echo -e "apple\nbanana\norange" | grep "a"
```

## Claude Code 体系中三者分别是什么

### 📖 Read — 读文件内容

- •
	**干的事** ：把指定文件（或文件的某几行）读进来给 Claude 看

- •
	**权限** ： **只读，不需要你授权**
- ```
	纯文本Read("src/auth.ts")              # 读整个文件
	Read("src/auth.ts", offset=50, limit=70)  # 只读第50~120行
	```

### 🔍 Grep — 按内容搜代码

- •
	**干的事** ：在整个代码库里按 **正则/关键字** 搜匹配行（底层是 ripgrep，很快）
- •
	**类比** ：安全的 `grep -r` ，但输出格式受控、可省 token
- •
	**权限** ： **只读，不需要你授权**
- •
	**典型场景** ：
	- •
		"找 `authenticate` 函数在哪被调用"
		- •
		"搜所有 TODO/FIXME"
		- •
		搜某变量的定义和使用位置
- •
	**关键限制** ：Claude Code 的 system prompt 硬性规定—— **能用 Grep 工具就别自己 Bash 里跑 `grep -r`**

### ⚡ Bash — 执行任意 Shell 命令

## 怎么选——决策树（最重要）

```
纯文本你要做的事 → 用哪个工具？

① 找"哪些文件叫 *.ts / *.test.ts"？
      → Glob（不是这三个里的，但常和它们配合）
        ↓ 拿到文件列表后再决定

② 找"代码里哪行出现了某个关键词/函数名"？
      → Grep ✅（最快、最省 token，只读安全）

③ 已经知道是哪个文件，想看里面写了啥？
      → Read ✅（带 offset/limit 读局部最好）

④ 要跑构建/测试/git/安装/任何系统级操作？
      → Bash ✅（唯一正确的选择）

❌ 反模式（Claude Code 会尽量避免）：
   用 Bash("cat file.ts")         → 应改用 Read
   用 Bash("grep -r pattern .")   → 应改用 Grep
   用 Bash("find . -name '*.ts'") → 应改用 Glob
```
