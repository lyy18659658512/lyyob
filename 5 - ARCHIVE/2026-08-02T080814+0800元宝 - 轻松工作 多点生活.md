## 核心思想的不同

**二分法（Bisection Method）** —— 靠"缩小包围圈"

- •
	利用 **介值定理** ：如果 f(a) 和 f(b) 异号，那么 (a,b) 区间内必有根
- •
	每次取中点 c=(a+b)/2，判断 f(c) 的符号，然后丢弃一半区间
- •
	本质上是"排除法"，不断把含根的区间长度减半

- •
	在当前点作切线，用切线与 x 轴的交点作为下一轮猜测
- •
	本质上是"用线性函数局部近似非线性函数"

用户延续前面对牛顿迭代法算平方根的讨论，核心是在问迭代过程“不停算下去”的终止条件。这个问题不需要查资料，关键是把数值计算中的停止准则讲清楚：既不能等“真正等于根”，也没有“无限次迭代”的意义，所以通常按近似误差、前后两步差值、残差大小或最大迭代次数来判定。结合前面平方根例子的化简公式，我可以说明实际算法里常用相邻两次迭代值的变化小于给定容差就停止，同时用残差或最大迭代次数防止不收敛时死循环。回答时要避免把牛顿法描述成一定会收敛；应强调初值、函数性质和停止阈值是决定“什么时候停”的实际因素。

这是一个非常 practical 的问题！牛顿法理论上可以无限迭代下去（因为根是实数时往往是无理数，永远算不到"精确等于"），所以实际应用中我们必须人为设定 **停止准则** 。

## 常用的五大停止准则

### 1\. 相邻两次迭代值的差足够小（最常用）⭐

其中 ε 是预设的容差（tolerance），比如 10⁻¹⁰。

**直观含义** ：最近两步的结果几乎没变化，说明已经收敛。

对于平方根例子 ，代码通常是：

```python
pythonx = 1.0
while True:
    x_next = 0.5 * (x + a/x)
    if abs(x_next - x) < 1e-10:  # 容差
        break
    x = x_next
```

### 2\. 函数值的绝对值足够小

**直观含义** ：当前的 x\_n 已经让 f(x\_n)≈0，即 x\_n 足够接近根。

对于平方根：检查 。

### 3\. 相对误差足够小

**适用场景** ：当根的大小尺度变化很大时，绝对误差不够用，需要用相对误差。比如求根接近 0 时，|x\_{n+1}-x\_n|<10⁻¹⁰ 可能太严；根很大时又可能太松。

### 4\. 达到最大迭代次数（安全网）🛡️

```python
pythonmax_iter = 100
for i in range(max_iter):
    x_next = 0.5 * (x + a/x)
    if abs(x_next - x) < 1e-10:
        break
else:
    print("警告：未达到精度要求")
```

**为什么必须有它** ：牛顿法并非总是收敛。如果初值选得太差，或者函数在某些点导数为 0，迭代可能：

- •
	震荡（在两个值之间来回跳）
- •
	发散（越算越大）
- •
	收敛到错误的根

没有最大迭代次数保护，程序可能陷入 **死循环** 。

### 5\. 组合准则（工业级做法）

实际数值计算库通常组合多个准则：

```python
pythondef newton_sqrt(a, tol=1e-15, max_iter=100):
    x = a  # 初值
    for i in range(max_iter):
        x_next = 0.5 * (x + a/x)
        # 准则1：相邻差值
        if abs(x_next - x) < tol:
            return x_next, i+1
        # 准则2：函数值
        if abs(x_next**2 - a) < tol:
            return x_next, i+1
        x = x_next
    return x, max_iter  # 返回最佳近似值
```

## 各准则的直观比较

| 准则 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- |
| 差值 \|xₙ₊₁−xₙ\|<ε | 简单直观 | 某些函数可能假收敛 | 一般通用 |
| 函数值 \|f(xₙ)\|<ε | 直接反映"根的质量" | 需要额外计算 f(xₙ) | 重视精度时 |

```
x₁ = 1.5         |x₁-x₀| = 0.5      > ε，继续
x₂ = 1.416666... |x₂-x₁| = 0.0833   > ε，继续
x₃ = 1.414215... |x₃-x₂| = 0.00245  > ε，继续
x₄ = 1.414213... |x₄-x₃| = 0.000002 < ε，停止！
```

只用了 **4 次迭代** 就达到了 10⁻⁶ 的精度。如果要求 ε = 10⁻¹⁵（双精度浮点数极限），大约需要 **6-7 次迭代** 。

## 关于"无限迭代"的理论思考

理论上，√2 是无理数，其二进制/十进制表示是无限的，所以：

- •
	如果坚持要"xₙ == √2 精确成立" → **永远停不下来**
- •
	如果接受"xₙ 足够接近 √2" → **几次迭代就停**

这也是为什么数值计算的核心是 **"近似"** 而非"精确"——在计算机的浮点数体系里，连 0.1 + 0.2 都不等于 0.3，我们本来就必须和误差共处。

> 💡 **一个有趣的边界情况** ：由于浮点数的精度限制，即使理论上应该继续收敛，实际计算中当 |xₙ₊₁−xₙ| 小到被浮点精度吞没时，xₙ₊₁ 可能等于 xₙ（出现"机器零"），这时迭代会自然停止——这其实也是一种隐式的停止准则。

---

**总结** ：牛顿法通过 **容差判断** （差值/函数值/相对误差小于阈值）来决定"够好了，停"，通过 **最大迭代次数** 来防止"永远停不下来"。两者结合，既保证了效率，又保证了安全性。对于平方根这种简单函数，通常 5-10 次迭代就能达到计算机浮点数的精度极限，这也是它成为硬件平方根指令首选算法的根本原因。
