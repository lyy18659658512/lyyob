# 知识库同步配置

知识库通过 **Git + Remotely Save（阿里云 OSS）** 双通道同步，各自分工。

## 双通道分工

| | Git | Remotely Save |
|---|---|---|
| **存储位置** | GitHub 仓库 | 阿里云 OSS（深圳） |
| **核心价值** | 版本历史、diff、回滚 | 跨设备无缝同步附件 |
| **适用设备** | 电脑 | 电脑、手机、平板 |

### Git 同步了什么

**✅ 同步：**

- 所有 Markdown 笔记（`.md`）
- `.obsidian/` 下几乎所有内容：
    - 插件本体（`main.js`、`manifest.json`、`styles.css`）
    - 插件配置（`data.json`）— Calendar、Dataview、Templater、Git 插件、Weread 等
    - 模板（`9 - SYSTEM/Templates/` 下的所有模板文件）
    - 其他 `.obsidian/` 核心配置（`app.json`、`appearance.json`、`community-plugins.json` 等）
- Git 历史记录（完整 commit 历史）

**❌ 不同步：**

- `6 - ATTACHMENTS/` — 图片、PDF 等附件（交给 Remotely Save）
- `.obsidian/workspace.json` / `workspace-mobile.json` — 工作区窗格布局（设备特有）
- `.obsidian/cache/` — 本地缓存
- `.obsidian/graph.json` — 图谱布局偏好
- `.trash/` — 已删除文件
- `.claudian/` — AI 工具本地缓存
- `.remotely-save/` — 同步插件的本地缓存
- Thumbs.db / .DS_Store — 系统垃圾
- Remotely Save 的 `data.json` — 含云存储凭证，插件自带 `.gitignore` 排除

### Remotely Save 同步了什么

**✅ 同步：**

- 所有 Markdown 笔记（`.md`）
- `6 - ATTACHMENTS/` — 图片、PDF、附件
- 其他所有不被排除的文件夹和文件

**❌ 不同步（由开关控制）：**

| 排除原因 | 对应设置 |
|----------|---------|
| `.obsidian/` 整个配置目录 | `syncConfigDir: false` |
| `_` 开头的文件/文件夹（如 `_templates/`） | `syncUnderscoreItems: false` |
| 书签 | `syncBookmarks: false` |

> `.git/`、`.trash/` 等隐藏文件夹由插件内置规则自动排除，不在 `ignorePaths` 里显式配置。

## Remotely Save 当前配置

### S3 连接信息

| 设置项 | 值 |
|--------|-----|
| Endpoint | `oss-cn-shenzhen.aliyuncs.com` |
| Region | `cn-shenzhen` |
| Bucket | `lyy-obsidian-note` |
| Remote Prefix | （空） |
| Force Path Style | `false` |
| Parts Concurrency | `20` |
| Bypass CORS Locally | `true` |

> ⚠️ **AccessKey ID / SecretAccessKey** 未记录在此（安全考虑）。去阿里云 RAM 控制台获取。

### 同步行为开关

| 开关 | 当前值 | 说明 |
|------|:---:|------|
| `syncConfigDir` | ❌ false | **不同步 `.obsidian/`** — 插件配置每台设备独立 |
| `syncUnderscoreItems` | ❌ false | 不同步 `_` 开头的文件/文件夹 |
| `syncBookmarks` | ❌ false | 不同步书签 |
| `syncDirection` | bidirectional | 双向同步 |
| `conflictAction` | keep_newer | 冲突保留较新版本 |
| `autoRunEveryMilliseconds` | 600000 | 每 10 分钟自动同步 |
| `encryptionMethod` | rclone-base64 | 路径混淆（密码为空） |
| `deleteToWhere` | system | 删除移入系统回收站 |
| `concurrency` | 5 | 并发数 |

### 排除 / 包含规则

| 设置 | 值 |
|------|-----|
| `ignorePaths` | `[]`（空，无额外排除） |
| `onlyAllowPaths` | `[]`（空，无白名单） |
| `skipSizeLargerThan` | `-1`（不限制） |

## 🖥️ 迁移到新电脑

### 前提

- 已安装 Git
- 已安装 Obsidian
- 已配置 GitHub SSH / 凭证

### 步骤

**1. Clone 仓库**

```bash
git clone <仓库地址> "SecondBrain"
```

这一步拉下：所有笔记、`.obsidian/` 配置（插件本体 + 所有插件配置）、完整 Git 历史。

> 仅 Remotely Save 的 `data.json` 不在 Git 中（含敏感凭证），需手动配置。

**2. 打开 Obsidian**

用 Obsidian 打开 clone 下来的文件夹作为 vault。首次打开可能需要等一会（插件加载）。

**3. 配置 Remotely Save**

打开设置 → 第三方插件 → Remotely Save → 填入：

- Service Type：**S3**
- Endpoint：`oss-cn-shenzhen.aliyuncs.com`
- Region：`cn-shenzhen`
- Bucket：`lyy-obsidian-note`
- AccessKey ID / SecretAccessKey：去阿里云控制台获取
- 其他保持默认即可

**4. 首次同步**

点 Remotely Save 的手动同步按钮，拉下 `6 - ATTACHMENTS/` 等附件。

> ⚠️ 首次同步附件较多，需等待几分钟。

**5. 验证**

运行 [[9 - SYSTEM/知识库操作规范#一致性检测|一致性检测]] 确认一切正常。

### 不需要做的事

- ❌ 不需要手动装插件（Git 已包含）
- ❌ 不需要配 Templater / Calendar / Dataview（配置在 Git 里）
- ❌ 不需要拷贝 `6 - ATTACHMENTS/`（Remotely Save 会拉）

## 📱 迁移到新安卓设备（手机 / 平板）

### 前提

- 已有另一台安卓设备在用知识库
- 两台设备在同一网络（Wi-Fi 直连传文件）

### 步骤

**1. 在旧设备上打包**

用文件管理器进入旧设备上的 vault 根目录，整个文件夹打包为 `.zip`。

> 重要：打包整个 vault，不只是笔记。这样 `.obsidian/` 配置一起带过去。

**2. 传输到新设备**

任选一种方式：

| 方式 | 适用场景 |
|------|---------|
| 茄子快传 / Send Anywhere | vault 较大，Wi-Fi 直连快 |
| LocalSend | 开源无广告 |
| 蓝牙 | vault 小（< 100MB） |
| 传到电脑再传新设备 | 没装上述 App |

**3. 新设备上解压**

- 安装 Obsidian
- 解压 zip 到内部存储
- Obsidian → 打开文件夹作为新 vault → 选择解压后的目录

**4. 首次同步**

打开 Remotely Save，点手动同步拉取最新笔记。

> 如果 Remotely Save 提示「远程已有数据」，选 **双向同步**，让插件自动合并。

**5. 清理工作区（可选）**

如果打开后 Obsidian 布局异常（屏幕比例不同导致），删除这两个文件让它重建：

- `.obsidian/workspace.json`
- `.obsidian/workspace-mobile.json`

### 不需要做的事

- ❌ 不需要装 Git（移动端用不了，也没必要）
- ❌ 不需要单独配置每个插件（从旧设备打包带过来了）
