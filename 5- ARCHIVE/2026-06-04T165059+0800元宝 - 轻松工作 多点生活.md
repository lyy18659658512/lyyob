齐次线性方程组是指常数项全为零的线性方程组。

其一般形式为：

```
纯文本a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = 0
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = 0
...
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = 0
```

或用矩阵方程表示为 **Ax = 0** ，其中 **A** 是系数矩阵， **x** 是未知数列向量， **0** 是零向量。

它的核心特性包括：

1. 1.
	**必有解** ：至少存在一个零解（平凡解），即所有未知数都取零。
2. 2.
	**解的结构** ：解的集合构成一个向量空间（称为解空间或零空间）。若有无穷多解，则全部解可由一组线性无关的基础解系线性表示。
3. 3.
	**有非零解的充要条件** ：当系数矩阵 **A** 的秩小于未知数的个数时，方程组存在非零解。

如何用点线面的直观来理解齐次线性方程组是否有解的问题

我们通常用“行图像”和“列图像”来直观理解线性方程组。对于齐次线性方程组 Ax=0，我们可以从两种图像来看，但因为它右边总是0，所以有一些特殊的几何意义。

首先，齐次方程组总是有解，至少有一个零解。问题在于它是否有非零解。我们可以从“列图像”和“行图像”两个角度来理解。

### 1\. 行图像（每个方程表示一个超平面）

每个方程 a\_i1 x1 +... + a\_in xn = 0 表示一个过原点的超平面（在二维是过原点的直线，三维是过原点的平面）。方程组的解就是这些超平面的交集。因为所有超平面都过原点，所以原点（零解）一定在交集中。是否有非零解，就看这些超平面是否交于一个除了原点之外的点（实际上，如果交于一个非零点，那么整个交是一条直线或一个子空间，因为齐次方程的解具有齐次性：如果x是解，那么kx也是解）。所以，从行图像看，就是看这些超平面的交集是否大于一个点。如果超平面的法向量线性相关，那么它们可能交于一个低维子空间。更具体地说，当方程个数小于未知数个数时，通常会有非零解（因为约束不够）；当方程个数等于未知数个数时，如果系数矩阵的行向量线性相关（即矩阵奇异），那么这些超平面交于一条线或子空间；如果行向量线性无关，那么交集只有原点。

### 2\. 列图像（线性组合）

将矩阵A按列分块，A = \[a1, a2,..., an\]，其中ai是m维列向量。那么方程 Ax=0 可以写成 x1 *a1 + x2* a2 +... + xn\*an = 0。这就是说，寻找一组系数x，使得A的列向量的线性组合为零向量。那么，是否有非零解，就相当于问：A的列向量是否线性相关。如果A的列向量线性相关，那么存在不全为零的系数x使得线性组合为零，即存在非零解。如果A的列向量线性无关，那么只有零解。

在几何上，列向量属于m维空间。如果列向量线性相关，意味着至少有一个列向量可以被其他列向量线性表示，或者这些列向量张成的子空间维数小于n。特别地，当n > m时（未知数个数大于方程个数），列向量必然线性相关（因为最多只有m个线性无关的向量），所以必有非零解。

### 3\. 从线性变换的角度

将A看作一个线性变换：从n维空间到m维空间。Ax=0就是问：有哪些向量x被映射到零向量。这些x的集合就是核（kernel）。零解对应零向量。是否有非零解，就是问这个线性变换的核是否不止零向量。如果线性变换不是单射，那么核的维数大于0，就有非零解。这等价于A的列向量线性相关（因为列向量是变换后的基向量的像，线性相关意味着维度压缩）。

总结：从几何角度，判断齐次线性方程组是否有非零解，就是判断系数矩阵的列向量是否线性相关（或行向量是否线性相关，或矩阵是否满秩）。如果列向量线性相关，则存在非零解；否则只有零解。在行图像中，这意味着超平面交于一个子空间（不止一个点）；在列图像中，意味着列向量可以线性组合出零向量（系数不全为零）。

我们可以用几何图像直观理解齐次线性方程组 **Ax = 0** 的解的情况。由于常数项全为零，其几何意义尤其特殊，主要体现在“行图像”和“列图像”两种视角。

- •

- •

- •

	如果法向量线性无关且个数等于未知数个数，则交集只有原点（仅有零解）。

超平面是线性空间（如我们熟悉的二维平面、三维空间，或更高维空间）中的一个概念，它是指 **比整个空间维度恰好低一维的平坦子空间** 。

### 直观理解

你可以把它想象成高维空间中的“平面”：

- •
	在 **一维** 空间（一条直线）中，超平面就是一个 **点** （维度为0）。
- •
	在 **二维** 空间（一个平面）中，超平面就是一条 **直线** （维度为1）。
- •
	在 **三维** 空间（我们生活的空间）中，超平面就是一个 **平面** （维度为2）。
- •
	在 **n维** 空间中，超平面就是一个 **n-1维** 的平坦子空间。

### 核心特征与方程

超平面的一个关键特性是，它可以用 **一个线性方程** 来定义。

- •
	在三维空间中，一个平面方程是： `ax + by + cz = d` 。
- •
	推广到n维空间，一个超平面的方程就是：
	`a₁x₁ + a₂x₂ + ... + aₙxₙ = b`
	其中 `(a₁, a₂, ..., aₙ)` 是常数（不全为零）， `b` 也是常数。

### 几何意义

1. 1.
	**法向量** ：方程中的系数 `(a₁, a₂, ..., aₙ)` 构成一个向量，称为这个超平面的 **法向量** 。它垂直于超平面内的所有向量。
2. 2.
	**分割空间** ：这个超平面将整个n维空间分割成两个“半空间”。例如，在二维中，一条直线将平面分成两个半平面；在三维中，一个平面将空间分成两个半空间。
3. 3.
	**齐次情形** ：当方程中的常数项 `b = 0` 时，即 `a₁x₁ + a₂x₂ + ... + aₙxₙ = 0` ，这个超平面一定经过 **坐标原点** 。这正是我们讨论齐次线性方程组时遇到的情况——每个方程都代表一个过原点的超平面。

### 为什么叫“超”平面？

“超”（Hyper）在这里是一个数学前缀，表示“在……之上”或“超越”，用于指代比我们日常感知的三维更高维度的事物。所以“超平面”就是高维空间中“平面”概念的推广。

**总结一下** ：超平面就是高维空间中的“平面”，它比所在空间少一维，可以用一个线性方程描述，并且具有法向量和分割空间的特性。在理解齐次方程组时，每个方程就代表一个过原点的超平面，方程组的解就是所有这些超平面的公共交点。
